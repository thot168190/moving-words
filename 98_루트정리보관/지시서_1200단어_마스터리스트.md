# 지시서 — 1200단어 마스터리스트 구축 (근거 기반 · 대표님 전수 검수)

> ✅ 대표님 지시 (2026-07-26): "유치하게 말고, 진짜 필요한 1200단어를 근거 있게. 내가 다 검수한다"
> ★ 전략 지위: 이 1200 리스트는 공개 노출을 두려워하지 않는다 — **후속 기획 전체(수능 코스·
>   단어 공방·노래 암기·중국어/일본어판)의 공통 발판 자산**이다. 베끼는 자는 목록을 가져가도
>   그림·노래·엔진·박물관은 못 가져간다. 따라서 확장을 전제로 제대로 만든다.
> 담당: 오퍼스 (딥마인드 사이언스 스킬 + 검색 병행) | 산출물: 검수용 시트 1장 (CSV)

## A. 선정 원천 (근거 3중 교차 — 출처 없는 단어 금지)
1. 교육부 2022 개정 영어과 기본 어휘 목록 (공식 앵커)
2. 중학 검정 교과서 빈출 코퍼스 (내신 직결)
3. 수능·모의고사 기초 빈출 어휘 (수능 뿌리 프레임)
- 각 단어에 출처 태그 필수: [교육부] [교과서] [수능뿌리] — 태그 2개 이상 우선 선발
- 목록 출처(문서명·URL) 명기. AI가 지어낸 '빈출' 주장 금지

## B. 품격 기준 (유치함 방지 — 챕터1 개편 어휘가 표준)
- 표준 예시: depth·vast·emerge·voyage·navigate·ancient·preserve·observe·phenomenon
- 유아 기초어(apple·dog·red 급)는 원칙 배제 — 장면 보조가 필요하면 '연관 단어' 칸에만
- 장면화 등급: [구체](그림 직행) / [반추상](장면 속 행위·상태) / [추상](문장·노래 담당)

## C. 시트 구조 (확장 열 포함 — 발판 설계)
No / 단어 / 뜻 / 출처태그 / 장면화등급 / 배정챕터(안) / 장면(안) /
수능확장태그(향후 수능 코스용) / 다국어예약(中·日 뜻 칸 비워둠) / 검수(대표님: O·X·교체어)

## D. 진행 방식
1. 오퍼스: 1200 초안 + 근거 완성 → data/ 폴더에 CSV 저장
2. 대표님 검수: 챕터 단위 100개씩 12회 분할 (한 번에 1200개는 사람 잡는 일)
3. 검수 완료 챕터부터 장면·노래 생산 라인 투입
4. 이견은 페이블-질문-대기함에

## 금지
- 출처 태그 없는 단어 / 유아어로 머릿수 채우기 / 검수 전 챕터의 생산 착수
