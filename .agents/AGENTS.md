# AGENTS.md — 코덱스 작업 규칙 (보는 단어장 / inkword.site)

> 이 파일은 코덱스가 매 작업 전에 반드시 읽고 따른다. 규칙 관리: 로부장.
> 정본은 GitHub main (thot168190/moving-words). 작업 전 `git pull`, 작업 후 `git push`.

## 0. 프로젝트
- 제품: 보는 단어장 (inkword.site) — 그림이 그려지는 과정으로 영어 단어를 익히는 학습 웹앱.
- 스택: Vite + React + TypeScript + Tailwind / Firebase(Auth·Firestore) / 결제는 PortOne / GitHub Pages·Netlify 배포.
- 학습장 본체: public/learning/index.html (독립 정적 파일).

## 1. 실행 원칙 (반드시 지킨다)
1. 지시된 것만 한다. 지시서/요청에 없는 파일·기능·리팩터링은 손대지 않는다.
2. 임의 창작·임의 수정 금지. 문구·색·레이아웃·폴더구조를 스스로 바꾸지 않는다.
3. 완료 = 자가검증 원문 출력. 작업 후 `grep -c` 등 검증 명령 결과를 원문 그대로 보고한다. 원문 없는 "완료했습니다"는 미완료로 간주한다.
4. 막히면 SKIP. 막힌 항목은 `SKIP: (이유)`로 표시하고 나머지를 끝까지 완주한 뒤 한 번에 보고한다. 단계마다 멈춰 승인 구하지 않는다.

## 2. 제품 헌법 (변경 금지)
1. 카피 동결 — 확정된 문구는 대표님 지시 없이 한 글자도 수정하지 않는다.
2. 그려짐의 법칙 — 그림은 그려지는 과정으로 등장한다. 완성본 즉시 노출 금지, 전 획 완주 후에만 채색/단어 전환.
3. 그림 진실의 법칙 — 단어는 그림에 실제 보이는 요소만 연결한다.
4. 폴더/파일명 임의 변경 금지.

## 3. 배포 절차
1. `npm run build`
2. dist 산출물을 dist-final에 복사 (robots.txt·sitemap.xml 포함 확인).
3. dist-final의 JS·CSS 짝과 mtime이 최신인지 확인 후 보고.

## 4. 결제 (PortOne)
- 결제는 PortOne. 시크릿 키는 절대 프론트에 노출하지 않는다(서버/서버리스 함수에서만 사용).
- 결제 확정은 서버가 PortOne 조회 API 또는 웹훅으로 검증한 뒤에만 처리한다.

## 5. 금지 상비군
- 카피 임의 수정 / 다른 파일·폴더 임의 생성·변경 / 미검증 라이브러리 사용 / 추측 보고 / 장황한 설명 / 승인 없이 중간 중단.
