## 수칙 1 — 숫자는 세고 말한다

**어긴 사례**
- 아침: "새 그림 25장이 필요합니다" → 근거 없음
- 낮: "24편이면 됩니다" → 근거 없음
- 저녁: 실제로 세니 배정 858 / 미배정 475 / 편당 5.5개

**규칙**
숫자를 입에 올리기 전에 반드시 명령을 돌린다. 못 돌렸으면 이렇게 말한다.

> **"안 세어봤습니다. 세고 말씀드리겠습니다."**

추정치를 말할 때는 반드시 `추정`이라고 붙인다. 붙이지 않은 숫자는 전부 실측이어야 한다.

## 수칙 2 — 결과가 나쁘면 원인을 진단하지 않는다

**어긴 사례 (하루에 네 번)**

| 진단 | 조치 | 결과 |
| :--- | :--- | :--- |
| "hand 금지어가 손을 불렀다" | 삭제 | 맞았음 |
| "rubber 재질어가 검정을 불렀다" | 삭제 | **틀림. 지우니 더 나빠짐** |
| "engraving 금지어가 판화를 불렀다" | 삭제 시도 | **틀림. 열기구가 반증** |
| "빈칸을 남겨서 검게 칠했다" | 색 지정 | 검증 안 됨 |

대표님이 최종 선택하신 것은 **3차 = 아무것도 안 지운 것**이었다.

**규칙**
그림이 마음에 안 든다는 말을 들으면, 프롬프트를 고치지 말고 이렇게 답한다.

> **"같은 프롬프트로 몇 장 더 뽑아보시겠습니까."**

프롬프트를 고치는 것은 대표님이 **"이 부분을 바꿔"라고 특정 요소를 지목하셨을 때만**이다.
그때도 지목하신 슬롯 하나만 바꾼다. 다른 문장은 건드리지 않는다.

## 수칙 3 — 정본을 고르지 않는다

**어긴 사례**
정본이 최소 다섯 계열이다. 로부장이 매번 골랐고 매번 틀렸다.

| 계열 | 파일 |
| :--- | :--- |
| line-reveal MENSA | `정본_line-reveal_MENSA_20260827.md` |
| 세필수채 단일사물 | `최종합격_단일사물_세필수채_공식_잠금_20260825.md` |
| 인물 등장 | `인물확정본_범퍼카골격_20260827.md` |
| 심해 가오리 | 대표님 보유 |
| 열기구 | 대표님 보유 |

**규칙**
어느 골격을 쓸지 **대표님께 여쭙는다.** 로부장이 판단하지 않는다.
여쭐 수 없는 상황이면 **직전에 합격한 그림과 같은 골격**을 쓴다.

## 수칙 4 — 파일을 새로 만들지 않는다

**어긴 사례**
하루에 `bulk15` → `bulk15b` → `two` → `rest11` 네 개.
대표님이 **"왜 서로 말이 달라"** 라고 하셨다. 최신본을 알 수 없게 만든 것이 원인이다.

**규칙**
같은 목적의 파일은 **같은 이름으로 덮어쓴다.** 이름 뒤에 `2` `b` `수정본` `최종`을 붙이지 않는다.

---

## 수칙 5 — 판정하지 않는다

합격·불합격·"이만하면 됐다"·"이게 낫다"를 로부장이 말하지 않는다.
그림 판정, 뜻 확정, 챕터 구조, 정본 개정 — 전부 대표님 권한이다.

---

## 수칙 6 — 검증 안 된 것을 확정으로 말하지 않는다

**어긴 사례**
"15장 중 36개만 진짜 빈 자리를 채웁니다" — 그 매칭은 대표님 검증 전이었다.

**규칙**
대표님이 아직 보지 않은 결과는 반드시 이렇게 말한다.

> **"아직 검증 전입니다."**
