## 1. 성공 문법의 핵심 2대 계열

### 🏛️ 계열 A: [사물·풍경·도감 씬] (TERRA, MOTUS, SOMNIUM 등)
- **대표 성공작:** 망원경, 비행기(MOTUS 1), 자전거(MOTUS 2), 벤치(MOTUS 3), 서재 창문(SOMNIUM 2), 시골길(TERRA 1), 물개 바위섬(TERRA 2)
- **핵심 특징:**
  1. 피사체 2~3개 단독 중앙 배치 (무거운 방 전체, 벽지, 바닥 제거).
  2. 0~4초: 15~20% 연한 연필선(Ultra-fine pale warm-grey graphite pencil lines)의 순차 드로잉.
  3. 4~8초: 80% 흰 여백을 살린 투명 수채화(Luminous transparent watercolor).
  4. 7~8초: 사물의 미세하고 우아한 1개 동작 (비행기 바퀴 구름, 촛불 흔들림, 나침반 바늘 회전).

### ☕ 계열 B: [인물·라이프스타일 씬] (SENSUS, SCHOLA, URBS 등)
- **대표 성공작:** 손거울(SENSUS 1B), 헤드폰과 머그잔(SENSUS 3), 알람시계(SENSUS 4)
- **핵심 특징 (핀터레스트 감성 드로잉):**
  1. **실사/웹툰/성인 초상화 100% 차단:** 노리타케/나가바 유 계열의 미니멀 2D 단선 드로잉 (`Noritake and Yu Nagaba inspired clean graphic line drawing`).
  2. **얼굴 묘사 락:** 점 2개 눈(Dot eyes) + 미니멀 일자 입술(Clean minimal straight-line mouth).
  3. **측면 3/4 앵글 활용:** 정면 증명사진을 피해 자연스러운 카페/테이블 옆모습으로 공간감 확보.
  4. **포인트 수채화:** 뺨에 맑은 살구빛 틴트(peach-coral blush on cheek) + 소품 포인트 1~2개(하늘색 거울/머그잔), 옷과 배경은 순백 유지.

## 2. 텍스트 누출 및 글리치 방지 4대 금기 헌법

1. **숫자/퍼센트/기호 절대 금지:** 프롬프트에 `10%`, `80%`, `16:9`, `(#FFFFFF)` 등을 쓰면 화면에 그대로 글자가 인쇄되므로 **단 1글자의 숫자/기호도 본문에 쓰지 않는다.**
2. **분할선/패널 단어 금지:** `left half`, `right side`를 잘못 쓰면 화면이 반으로 쪼개지므로, `The single unified scene is centered...` 단일 화면 산문으로 서술한다.
3. **먹물 톤다운 금지:** 칙칙한 갈색/회색 워시 대신 맑은 파스텔 톤 수채화 사용.
4. **오른쪽 공백 쏠림 방지:** 테이블 선을 수평으로 자연스럽게 오른쪽까지 연장하여 가로 16:9 화면을 시원하게 채운다.
