## 0. 배경 — 2차 배포 후 대표님 피드백

2차 배포(`index-CYsBUkpM.js`)로 **잘림과 세로 위치는 해결됐다.** 스크린샷 확인 완료.
남은 문제: **글자가 너무 작아 읽을 수 없다.**

원인 2개:

| # | 원인 | 설명 |
|---|---|---|
| 1 | **`perspective:340px`의 원근 축소** | `rotateX(22deg)`로 눕힌 면을 340px 앞에서 보는 설정. 화면 위쪽(먼 쪽)이 **0.7~0.85배로 축소**된다. 14px가 실제로는 10~12px로 보였다. 이것이 주범이다. |
| 2 | **폰트 하한이 낮음** | 2차에서 `clamp(14px, 3.6vw, 64px)`로 잡았다. 잘림을 막는 데만 집중해 지나치게 보수적이었다. |

**왜 2차에서 폰트를 더 못 키웠나** — `whiteSpace:'pre'`는 자동 줄바꿈이 없어서
가장 긴 줄(21자)이 한 줄에 다 들어가야 했다. 키우면 잘렸다.
**3차에서 `pre-wrap`으로 바꿔 이 제약을 없앴다.** 이제 넘치면 접히므로 잘릴 수 없다.

## 1. 이미 반영된 변경 (코다리는 다시 만들지 않는다)

| # | 파일 | 변경 |
|---|---|---|
| 1 | `dist/assets/index-CYsBUkpN.js` | **신규.** 구 `index-CYsBUkpM.js`에 3곳 패치 |
| 2 | `dist/index.html` | 참조 `index-CYsBUkpM.js` → `index-CYsBUkpN.js` |
| 3 | `src/App.tsx` (230·233줄) | 번들과 동일 내용으로 소스 동기화 |
| 4 | `_to_delete/index-CYsBUkpM.js` | 구 번들 백업 (되돌릴 때 사용) |

`public/learning/index.html`과 `dist/learning/index.html`은 **2차 그대로, 손대지 않았다.**

### 패치 3곳

```
(1) 줄바꿈 방식 — 잘림 원천 차단
    before: whiteSpace:"pre"
    after : whiteSpace:"pre-wrap"
    ※ 크롤 텍스트 하나만. 페이지 안의 다른 whiteSpace:"pre-line" 2곳은 그대로 둔다.

(2) 글자 크기
    before: fontSize:"clamp(14px,3.6vw,64px)"
    after : fontSize:"clamp(22px,6vw,64px)"

(3) 원근 강도
    before: style:{perspective:"340px"}
    after : style:{perspective:"900px"}
```

### 크기 변화 실측

| 화면폭 | 2차 폰트 | 3차 폰트 | 배율 |
|---|---|---|---|
| 360px | 14px(하한) | 22px(하한) | **1.57배** |
| 390px | 14.0px | 23.4px | **1.67배** |
| 430px | 15.5px | 25.8px | **1.66배** |
| 768px | 27.6px | 46.1px | 1.67배 |
| 1067px 이상 | 38~64px | 64px(상한) | 동일 |

여기에 원근 축소 완화분이 더해진다 — 화면 위쪽 기준 2차 0.82배 → 3차 0.93배.
**체감 배율은 약 1.9배.**

## STEP 1 — 검증 (배포 전)

```bash
cd <워크스페이스 루트>

node --check dist/assets/index-CYsBUkpN.js && echo "문법 PASS"

grep -c 'clamp(22px,6vw,64px)'   dist/assets/index-CYsBUkpN.js   # 기대 1

grep -c 'clamp(14px,3.6vw,64px)' dist/assets/index-CYsBUkpN.js   # 기대 0

# pre-wrap 1개 · pre-line 2개여야 한다 (다른 곳 오염 없음 확인)
grep -o 'whiteSpace:"[a-z-]*"' dist/assets/index-CYsBUkpN.js | sort | uniq -c
# 기대: 2 whiteSpace:"pre-line" / 1 whiteSpace:"pre-wrap"

grep -o 'index-[A-Za-z0-9]*\.js' dist/index.html                 # 기대 index-CYsBUkpN.js
ls dist/assets/                                                   # 기대 index-CYsBUkpN.js, index-CkJuY0it.css 만
grep -rn 'index-CYsBUkpM' dist/ | wc -l                          # 기대 0

# 2차 성과가 유지되는지 (학습 페이지는 건드리지 않았다)
python3 - <<'PY'
import io,re
for p in ["public","dist"]:
    s=io.open(p+"/learning/index.html",encoding="utf-8").read()

PY
# 기대: public 빈칸: 0 크기: 212173 / dist 빈칸: 0 크기: 212173
```

## 코다리가 하지 말 것

- `npm run build` — 심사 중, 번들 해시가 바뀌면 검증 경로가 전부 깨진다

- `learning/index.html` 건드리기 — 2차 결과물이 이미 라이브에서 정상이다
- 크롤 섹션 자체를 제거하기 — 제거는 심사 통과 후 디자인 개편 때 대표님 판단으로 한다
