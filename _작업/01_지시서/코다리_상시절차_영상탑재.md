# 1부. 상시 절차 (앞으로 계속 이대로)

## 트리거

대표님이 `public/learning/챕터N_완성동영상/` 폴더에
**`Line-reveal_...mp4` 같은 Flow 원본 이름의 파일**을 넣으면 이 절차가 시작된다.
대표님이 "넣었어"라고만 말해도 아래를 전부 수행한다.

---

## STEP 1 — 이름 정리

```bash
D="public/learning/챕터N_완성동영상"
ls -1 "$D"/scene-chN-*.mp4 | sort | tail -1     # 현재 최대 번호 확인
```

새 파일은 **최대 번호 + 1**부터 순서대로 `scene-chN-XX.mp4`로 바꾼다.

**어느 파일이 몇 번인지는 Flow 원본 이름의 영어 단어로 판별한다.**
예: `..._of_washing…` → 빨랫줄 편, `..._of_boots…` → 부츠 편

판별이 안 되는 파일이 하나라도 있으면 **여기서 멈추고 파일명 목록을 그대로 보고**한다.
추측해서 붙이지 않는다.

---

## STEP 2 — 오디오 제거

Flow 영상에는 오디오 트랙이 살아 있어 랜딩에서 잡음이 샌다. 전부 제거한다.

```bash
for f in 새로_붙인_번호들; do
  ffmpeg -y -loglevel error -i "$D/scene-chN-$f.mp4" -c copy -an "$D/_t.mp4" \
    && mv "$D/_t.mp4" "$D/scene-chN-$f.mp4"
done
```

- `-c copy` 필수. **재인코딩하면 화질이 떨어진다.**
- 검증은 아래 방식으로 한다. **`&& echo` 방식은 쓰지 마라 — ffprobe는 출력이 비어도 exit 0이라 항상 통과한다.**

```bash
for f in 번호들; do
  echo -n "$f "; ffprobe -v error -select_streams a -show_entries stream=index -of csv=p=0 "$D/scene-chN-$f.mp4" | wc -l
done
# 전부 0 이어야 한다
```

## STEP 3 — 포스터 생성

```bash

```

7.4초는 그림이 완성된 시점이다. 바꾸지 마라.

## STEP 4 — 채도 보정

**확정값이 정해진 뒤에만 수행한다. 값은 로부장이 통보한다.**
값을 못 받았으면 이 단계를 건너뛰고 그렇게 보고한다.

```bash
ffmpeg -y -loglevel error -i 입력.mp4 -vf "eq=saturation=<확정값>:brightness=0.03:contrast=0.95" -c:a copy 출력.mp4
```

## STEP 6 — index.html 데이터 추가

`dist/learning/index.html`과 `public/learning/index.html` **양쪽 모두** 수정한다.
한쪽만 고치면 다음 빌드 때 사라진다.

`chapterData[N]`에는 배열이 **5개** 있다. 하나라도 빠뜨리면 영상은 뜨는데 단어가 안 나온다.

```js
chapterData[N] = {
  works:         [],   // 편마다 { title, video, poster, words[] }
  levelOneWords: [],   // 편마다 1단계 단어 배열
  levelTwoWords: [],   // 편마다 2단계 단어 배열
  sceneSpots:    [],   // 편마다 2단계 단어의 화면 좌표
  levelOneSpots: [],   // 편마다 1단계 단어의 화면 좌표
}
```

### 단어를 1단계 / 2단계로 나누는 법

**단어를 창작하지 않는다.** 로부장이 준 목록 그대로 쓴다.
1단계·2단계 구분은 `_작업/1200_레벨태그_v3.csv`를 **조회**해서 정한다.

- csv에서 레벨1인 단어 → `levelOneWords`
- csv에서 레벨2인 단어 → `levelTwoWords`
- **csv에 없는 단어가 하나라도 있으면 멈추고 보고한다.** 정본 밖 단어다.

`words`는 1단계 먼저, 2단계 나중 순서로 이어 붙인다.

### 좌표(spots)

좌표는 그림을 보고 정해야 하는 판단 영역이다. **코다리가 만들지 않는다.**
로부장이 좌표를 함께 주면 그대로 넣고, 안 줬으면 **좌표 없이 나머지만 넣고 "좌표 미수령"이라고 보고**한다.

## STEP 7 — 검증 (배포 전 필수)

```bash
node -e "
const fs=require('fs');
const s=fs.readFileSync('dist/learning/index.html','utf8');
const m=s.match(/chapterData\[(\d+)\]\s*=\s*(\{[\s\S]*?\n\s*\});/g)||[];
console.log('챕터 블록 수', m.length);
"
```

각 챕터마다 아래를 직접 세어서 **표로 보고**한다.

```
[ ] works.length
[ ] levelOneWords.length
[ ] levelTwoWords.length
[ ] sceneSpots.length
[ ] levelOneSpots.length
   → 이 다섯 숫자가 전부 같아야 한다
[ ] 각 편의 levelOneWords[k].length + levelTwoWords[k].length == works[k].words.length
[ ] 각 편의 sceneSpots[k].length == levelTwoWords[k].length
[ ] 각 편의 levelOneSpots[k].length == levelOneWords[k].length
[ ] chapterData 안의 모든 video / poster 경로가 dist/learning 아래에 실제로 존재
```

**하나라도 어긋나면 배포하지 말고 보고한다.**

> 지난 사고: works만 붙이고 나머지 4개를 빠뜨려 영상은 뜨는데 단어가 안 나왔다.
> 원인은 검증이 `works.length`만 셌기 때문이다. 이제 다섯 개를 전부 센다.

## STEP 8 — 배포

```bash
npx gh-pages -d dist
```

- `npm run deploy` **금지** — predeploy가 build를 돌려 심사 중인 결제 번들을 재생성한다
- `npm run build` **금지** — 같은 이유
- Netlify 배포 금지. `gh-pages` 브랜치가 정본
- gh-pages 히스토리 삭제·강제 리셋 금지

한글 폴더명이 macOS 자모분리(NFD)라 `git add`에서 누락되는 일이 있다. 파일이 안 올라갔으면:

```bash
git -c core.precomposeunicode=true add -A
```

## 보고 형식 (매번 이 형식으로)

```
1) 이름 변경 결과   원본이름 → scene-chN-XX.mp4  (표)
2) 오디오 스트림 수  편별 숫자 (전부 0이어야 함)
3) 포스터 생성 결과  파일명 + 바이트
4) dist 동기화 diff  (비어 있어야 함)
5) 5배열 길이 표     works / L1 / L2 / spots / L1spots
6) 편별 세부 검증    단어 수 == L1+L2, spots 수 일치 여부
7) 경로 존재 확인    없는 파일 목록 (없으면 "없음")
8) 배포 여부 + gh-pages 커밋 해시
```
