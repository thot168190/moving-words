# 코덱스 지시서 — 구매 CTA 복원 (PG 심사 대응 · 2026-07-31 긴급)

> 배경: PG 심사 진행 중. 심사역이 사이트에서 구매 동선을 확인할 수 있어야 한다.
> 사전신청 전환 때 '구매' CTA가 사라짐 — 복원한다. 단, 가짜 결제창은 절대 금지.

## 작업 (pricing 섹션)
1. 가격 카드의 주 버튼을 **[이용권 구매하기]** 로 복원 (딥그린, 가장 눈에 띄는 위치)
2. 클릭 시 동작: 같은 페이지의 안내 블록으로 이동 —
   "결제 수단을 연결하고 있습니다. 이메일을 남겨주시면 결제 오픈 즉시 알려드리고, 출시 기념가 ₩9,900을 그대로 보장해 드립니다."
   + 기존 사전신청 폼(이메일+알림 신청) 그대로 노출
3. 즉, 구매 의사 → 이메일 예약으로 이어지는 한 줄 동선. 기존 Firestore 저장 로직 재사용
4. 상품명·가격·혜택 목록·환불 규정 문구(7일 이내 전액 환불, 약관 제5조)는 현 위치 유지 — 심사역 확인 요소이므로 숨기지 않는다

## 금지
가짜 결제창·카드입력 UI 흉내 절대 금지 / 가격·환불 문구 수정 금지 / 다른 페이지 변경 금지

## 완료 판정
배포(커밋해시+로그) + [이용권 구매하기] 버튼이 보이는 데스크톱·**390px** 스크린샷 + 클릭→사전신청 도달 스크린샷
