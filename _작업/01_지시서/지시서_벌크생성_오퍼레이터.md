# 코다리 지시서 — Flow 벌크 생성 오퍼레이터 (2026-08-07)

> 역할: 기계 오퍼레이터. 프롬프트 판단·수정·품질 판정은 전부 금지 — 실행·수확·기록만 한다.
> 도구: 크롬 확장 `철만이/_도구/cheolmani-flow-bulk-v503` (설치: chrome://extensions → 개발자 모드 → 압축해제 로드)

## 입력
- `_작업/벌크입력/` 의 **"S"자 붙은 파일만** (벌크_01_S013-S027.txt ~ 벌크_10). S 없는 구파일 사용 금지
- Flow는 대표님 계정으로 로그인된 브라우저 프로필에서 연다. 로그인 시도·비번 입력 절대 금지 — 로그인 안 돼 있으면 멈추고 보고

## 실행 절차 (배치 단위 반복)
1. Flow 새 프로젝트 열기 → 확장 사이드패널 → **인그리디언트 칸 비워둠**
2. 배치 파일 내용 전체를 프롬프트 칸에 붙여넣기 → 대기시간 120초 이상 → 시작
3. 배치 완료 후: 각 컷 성공/실패 기록. 실패 컷은 **같은 프롬프트로 재시도 1회만** — 2회 실패 시 표에 기록하고 건너뜀
4. 성공 영상 전부 다운로드 → `_작업/신작영상/벌크수확/` 에 **S번호.mp4** 파일명으로 저장 (예: S1-042.mp4)
5. **배치마다 Flow 크레딧 잔량 스크린샷** → `_작업/03_증거/벌크크레딧/` 저장
6. ⛔ 크레딧 잔량이 **20% 이하**로 떨어지면 즉시 전체 중단 후 보고

## 절대 금지
프롬프트 수정·요약·재작성 / 재시도 2회 이상 / 품질 판정·삭제 / 인그리디언트 사용 /
사이트·저장소(git)·scenes 폴더 접촉 / 대표님 계정 설정 변경
