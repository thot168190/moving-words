# 코다리 지시서 — 이용권 버튼 사전신청 연결 (2026-07-31)

> 증상: 결제벽 모달의 [이용권 보러 가기 →]가 홈으로 떨어짐 (연결 대상 없음).
> 배경: PG(결제) 미개통. 개통 전까지 사전신청으로 수요를 모은다.

## 작업
1. [이용권 보러 가기] 클릭 → `/pricing`(이용권 안내 섹션/페이지)로 연결. 내용:
   - 이용권 안내: 출시 기념가 ₩9,900 · 한 번 결제로 계속 이용 (기존 카피 그대로 — 카피 창작 금지)
   - 안내문: "결제 오픈을 준비하고 있습니다. 이메일을 남겨주시면 오픈 즉시 알려드리고, 출시 기념가를 그대로 보장해 드립니다."
   - 이메일 입력 1칸 + [알림 신청] 버튼
2. 이메일 저장: 서버/DB 없이 가능한 가장 단순한 방식 (예: Formspree·Tally 등 무료 폼 연동 또는 기존 백엔드 있으면 그것). **API 키·계정 생성이 필요하면 멈추고 보고 — 대표님이 직접 만든다**
3. 신청 완료 시 확인 문구: "신청되었습니다. 오픈 소식으로 찾아뵙겠습니다."
4. 모달의 [계속 둘러보기]는 현행 유지

## 금지
가격·카피 임의 수정 / 결제 기능 흉내(가짜 결제창) 금지 / 다른 페이지 변경 금지

## 완료 판정
1. 배포(커밋해시+deploy 로그) 2. [이용권 보러 가기] 클릭 시 사전신청 화면 도달 스크린샷 3. **390px 모바일 스크린샷** 4. 테스트 이메일 1건 제출→수신(또는 저장) 증빙 원문
