## STEP 2 — 한 편씩 좌표 찍기

**한 편 처리 순서**

1. `poster` 이미지를 연다
2. `levelOneWords` + `levelTwoWords` + `추가단어` 를 합친 목록을 본다
3. 각 단어가 **그림에서 가리키는 대상**을 찾는다
4. 그 대상의 위치를 **가로 %(왼쪽 0 → 오른쪽 100), 세로 %(위 0 → 아래 100)** 로 적는다
5. `levelOneSpots_새로` / `sceneSpots_새로` 에 채운다

### ★ 최상위 기준 — 대표님 지시 (2026-08-21)

> **"정상적으로 보이느냐가 기준이야. 거기에 부합하는 쪽으로 해."**

아래 규칙은 **최소선**이지 목표가 아니다. 규칙을 다 지켜도 화면에서 어색하면 실패다.
좌표를 다 찍은 뒤 **그림을 다시 열어 이렇게 자문하라.**

1. 글자가 **주인공을 가리고 있지 않은가** — 고래 얼굴, 얼음 덩어리처럼 그림의 중심은 비워둔다
2. 글자끼리 **부딪히거나 겹쳐 보이지 않는가** — 거리 18은 최소선이다. 긴 단어(`temperature`, `countryside`, `fascinate`)는 가로로 길게 뻗으니 **더 띄운다**
3. 한쪽에 **몰려 있지 않은가** — 화면을 4등분했을 때 한 칸에 3개 이상 모이면 다시 본다
4. 긴 단어가 **가장자리에 붙어 잘리지 않는가** — 글자 수가 많을수록 x를 중앙 쪽으로 당긴다
5. 하늘·여백처럼 **아무것도 없는 데 떠 있지 않은가** — 추상어라도 관련된 사물 근처에 둔다

**규칙과 보기가 충돌하면 보기 좋은 쪽을 택한다.** 단 아래 둘은 예외 없다 — 어기면 페이지가 죽거나 글자가 잘린다.

- 좌표 개수 ≥ 단어 개수
- x, y 는 8~92 범위

**규칙**

| # | 규칙 | 이유 |
|---|---|---|
| 1 | x, y 는 **8 이상 92 이하** | 화면 가장자리에 붙으면 글자가 잘린다 |
| 2 | 같은 레벨 안 두 좌표 사이 거리 **18 이상** | 단어끼리 포개진다. 거리 = √((x1-x2)²+(y1-y2)²) |
| 3 | 단어가 가리키는 것 **위에, 없으면 바로 옆** | 이게 이 작업의 전부다 |
| 4 | 좌표 개수 ≥ 단어 개수 | 부족하면 `spots[i]`가 비어 **그 편이 통째로 안 열린다** |
| 5 | 남는 좌표는 그대로 둬도 된다 | 안 쓰인다. 다만 규칙 1·2는 지킬 것 |
| 6 | 그림에 없는 것은 **억지로 찍지 말고 보고** | 단어 배정이 틀린 것이다. 좌표로 해결할 문제가 아니다 |

**레벨1과 레벨2**

- `levelOneWords` → `levelOneSpots` · 레벨1은 **퀴즈에 쓰인다**(`slice(0,4)`). 서로 확실히 떨어뜨릴 것
- `levelTwoWords` → `sceneSpots`
- 추가단어는 **레벨2(`levelTwoWords` + `sceneSpots`)에 붙인다.** 레벨1은 4개를 넘기지 않는다

**추상어는 이렇게 찍는다** — `climate`(기후), `doubt`(의심)처럼 눈에 안 보이는 단어는 **그 뜻이 가장 잘 드러나는 부분**에 찍는다. 예: `climate`는 하늘 쪽, `flame`은 모닥불 위, `aloud`는 이야기하는 사람 입 근처.

**이 22개는 로부장이 기계 검증을 마쳤다.** 전부 정본 1200 안에 있고, 다른 편에서 안 쓴 단어이고, 뜻이 기존·신규 어디와도 겹치지 않는다. **단어와 뜻을 임의로 바꾸지 마라. 판정은 대표님만 한다.**

**넣는 자리 3곳 — 빠뜨리면 페이지가 죽는다**

```
works[k].words        ← 맨 뒤에 ["영어","뜻"] 추가
levelTwoWords[k]      ← 같은 쌍을 맨 뒤에 추가
sceneSpots[k]         ← 그 단어의 좌표를 같은 순서로 추가
```

`ch10-03`은 추가단어가 4개라 `sceneSpots`가 지금 4칸으로 부족하다. **좌표를 새로 만들어 6칸으로 늘려야 한다** (기존 steam·temperature 2 + 추가 4).

**그림에 그 단어가 정말 없으면** — 억지로 넣지 말고 그 단어만 빼고 진행한 뒤 보고하라. 22개를 다 못 넣어도 된다. 틀린 자리에 넣는 것보다 낫다.
