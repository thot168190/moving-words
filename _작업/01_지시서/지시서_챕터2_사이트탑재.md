# 코다리 지시서 — 챕터2 학습 콘텐츠 사이트 탑재 (2026-08-06)

> 성격: 기계 작업 + 데이터 입력. **창작 0** — 아래 확정표 밖의 단어·뜻·문구를 한 글자도 만들지 마라.
> 시작 전: 편집기 버퍼 전부 닫고 디스크 최신 파일을 새로 연다.

## 입력
- 원본 영상: `_작업/신작영상/챕터2/` (대표님이 Flow 합격본을 넣는 폴더)
- 장면↔파일 대응은 대표님이 파일명 또는 메모로 지정한 것을 따른다. 불명확하면 **멈추고 질문**

## 공정 (순서 고정)
1. 원본 백업 → `_작업/99_보류_폐기/영상원본_챕터2/`
2. 톤 보정: `도구_톤다운/톤다운.sh` 현재 기본값으로 일괄 처리
3. 파일명 부여: `scene-ch2-01.mp4` ~ 순서대로 (아래 표 순서) → `public/learning/챕터2_완성동영상/`
4. 포스터: **끝 프레임**에서 추출 — `ffmpeg -sseof -0.5 -i 영상.mp4 -frames:v 1 -q:v 2 영상-poster.jpg`
5. 학습 페이지에 챕터2 장면 데이터 추가 (아래 확정표 그대로). 레벨1/레벨2 탭 분류는 `_작업/1200_레벨태그_v3.csv` 조회로만
6. 접근 정책: **챕터2 전체 = 이용권 구역(잠금)**. 무료는 챕터1 앞 3장면 현행 유지
7. 커밋: 변경 파일만 add (add -A 금지) → push → `npm run deploy`
