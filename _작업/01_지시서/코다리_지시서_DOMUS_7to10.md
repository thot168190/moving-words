## 3. 절대 규칙 (오늘 사고로 얻은 것들)

**① 마지막 동작은 "제자리 미세 변형" 하나뿐이다**
- 되는 것 — 문이 조금 열림, 사슬이 한 번 흔들림, 소매가 한 번 흔들림
- **안 되는 것** — 물건이 A에서 B로 **이동**하는 것
  둥지 편에서 "풀이 밖에서 안으로 들어감"을 넣었더니, Veo가 마지막에 화면을 다시 그리면서
  **새를 지웠고 다음 판에서는 알을 지웠다.** 여섯 번 다시 뽑았다.
- `[D]` 문장을 그대로 쓰고 새로 쓰지 마라.

**② 긍정문(`Never:` 앞)에 소환어를 쓰지 마라**
막으려고 적은 단어가 오히려 불려 나온다. 실제 사고:
`hand`→손 등장 · `pen`→펜 등장 · `dark-charcoal`→잉크 드로잉 · `narration`/`voice`→**남성 음성 삽입**
차단은 전부 `Never:` 블록에서 한다.

**③ `densely` `pressed close together` 같은 밀도 지시 금지**
선이 촘촘해지면서 옅은 수채가 진한 연필 덩어리가 된다.

**④ 단어를 창작하지 마라**
위 24개 단어가 전부다. 하나도 바꾸지 말고 하나도 더하지 마라.
`window` `corner` `basin` `hanger` `gloves`처럼 **정본 1200 밖 단어를 넣으면 그 편은 폐기된다.**

## 4. 제출 전 스스로 검사할 것

각 파일마다 아래를 직접 확인하고 **결과를 함께 보고**한다.

```
[ ] 골격 문장이 1편과 글자 단위로 같은가 (A~F 여섯 곳 제외)
[ ] Never: 앞에 hand / pen / pencil / brush / tool / paper / charcoal /
    narration / voice / children / figure(단, 10편의 figure는 허용) 가 없는가
[ ] 7-8s가 "제자리 미세 동작 + 멈춤"으로 끝나는가 (이동 동작 없음)
[ ] densely / pressed close 같은 밀도 지시가 없는가
[ ] 배정 단어 6개가 [A] 피사체 목록에서 전부 눈에 보이는 물건으로 나오는가
[ ] Audio 문단과 Never 문단을 1편에서 그대로 복사했는가
[ ] 10편 외에는 사람이 없는가
```
