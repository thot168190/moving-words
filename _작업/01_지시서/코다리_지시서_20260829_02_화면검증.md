## 0. 왜 이 지시서가 나왔나 (사실 기록)

대표님이 챕터4 화면을 보시고 **글자가 서로 겹쳐 안 읽히는 것**을 잡아내셨다.
로부장은 그 직전에 "검증 오류 0, 좌표 겹침 0"이라고 보고했다. **그 보고가 틀렸다.**

원인: 로부장이 좌표를 **중심점 사이 거리 6%** 로만 쟀다.
실제로는 `sentence 문장` 한 덩어리가 가로 12.8% · 세로 10.7% 를 차지한다. 6% 로는 완전히 포개진다.

**로부장은 앱 화면을 한 번도 열어보지 않았다.** 데이터만 보고 정상이라고 했다.
그래서 이번에는 **화면을 눈으로 본 것만 인정한다.**

## 1. 로부장이 방금 고친 것 (이미 파일에 반영됨)

### 1-1. 글자 겹침 — 205편 전부 좌표 재계산
실제 CSS 규격(`.scene-word`)에서 라벨 크기를 계산해 사각형이 안 겹치도록 밀어냈다.
- 영문 25px / 9자 이상 32px / 12자 이상 28px, 한글 22px 둘째 줄, 흰 테두리 6px
- 겹침 **687쌍 → 0쌍**
- 스크립트: `~/Downloads/fixspots.py`

### 1-2. 빈 탭 — UI 수정 (데이터 아님)
접속사만 있는 장면은 레벨1이 **없는 게 정상**인데 앱이 빈 탭을 그대로 보여줬다.
`renderWords()` 앞에 `syncLevelTabs()` 를 넣어 **빈 레벨 탭을 숨기고 자동으로 반대 레벨로 전환**하게 했다.
→ 해당 18편(L1빈 7 · L2빈 11)이 한 번에 해결된다.

### 1-3. 밀도 — 10편을 20편으로 분할
단어 10개 이상이면 글자가 그림을 덮는다. 같은 영상을 쓰고 단어만 반씩 갈랐다.

## 3. 이상 없으면 배포

```bash
cd ~/workspace/움직이는그림사전
python3 "$HOME/Downloads/fixspots.py" public/learning/index.html   # 겹침 0 확인용, 다시 돌려도 안전
npm run build
npm run deploy
git add public/learning/index.html && git commit -m "fix(learning): 라벨 겹침 해소·빈 레벨탭 숨김·밀도 10편 분할 (205편)" && git push origin main
```

> `npm run build` 는 이번엔 **돌려야 한다.** 배포가 `gh-pages -d dist` 방식이라 dist 를 새로 만들어야 반영된다.
> 번들 해시는 `src/` 를 안 건드리면 그대로다(오늘 확인: `index-BtRbmCWq.js` 동일).

배포 뒤 확인:
```bash
git log origin/gh-pages -1 --format='%ci %s'
```
