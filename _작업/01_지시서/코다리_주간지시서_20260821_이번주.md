## 2. 왜 손이 나오는가 — 이건 외워라

| 쓴 것 | 나오는 것 |
|---|---|
| `never two hands` `no artist, hand, pen or tool` | **손.** 모델은 부정어를 흘리고 명사만 가져간다 |
| `There are no ... drawing tools anywhere` | **손.** 위와 동일 |
| `draws itself` `by itself` | 손 |
| `spreading` 같은 붓질 동사 | 손·붓·종이질감 |
| `whiteboard` | 화이트보드라는 물건 = 흰 카드 액자 |
| `pencil` `graphite` | 연필 든 손 + 힘없는 선 |
| `paper` `cream` `parchment` | 액자·종이질감 |
| `Never:` 목록 | 거기 적은 명사들이 오히려 소환됨 |

**손을 막는 방법은 금지가 아니라 언급 자체를 없애는 것이다.**
대신 정본이 쓰는 이 문장 하나가 손을 막는다.

```
The only visible subjects throughout the sequence are {요소1}, {요소2}, {요소3}, {요소4} and {요소5}.
```

잠금 파일이 **"폭주를 막는 장치, 절대 빼지 마라"**로 표시해둔 문장이다. 보이는 게 다섯뿐이라고 못박으면 손이 낄 자리가 없다. 산호협곡이 손 없이 나온 이유가 이것이다.
