# 코다리 지시서 — 생산 작업대 v3 (전체 장면 일괄 관리)

> 발신: 로부장 | 목적: 장면 1개씩이 아니라 **카탈로그 전체**를 한 화면에서 조립·발사·판정한다.
> ⚠️ 새로 짜지 마라. 기존 `_작업/장면작업대.html`(v2 단순판)을 **베이스로 확장**한다.
> v2의 골격 상수·조립 함수·판정 5항목·기록 로직은 검증 완료 — 재사용하고 변형 금지.

## A. 데이터 파일 신설: `_작업/scenes-catalog.json`
```json
{ "scenes": [
  { "id":"ch1-01", "name":"고래와 깊은 바다", "type":"와",
    "sa":"", "sb":"", "sc":"", "status":"빈칸" }
] }
```
- status 값: 빈칸 → 조립됨 → 합격 / 불합격
- 초기 시드: 챕터1 8장면(고래·등대·범선·콜로세움·별자리·오로라·열기구·산호) 스캐폴드 생성.
  이미 완성된 장면(범선 등)은 슬롯 값 채워 넣기 — 오퍼스가 오늘 만든 1개 장면의 슬롯도 회수해 입력
- type: 와/쉼 (챕터 리듬 규칙 — 첫·끝 장면은 와)

## B. 화면 구성 (딱 2단 — 이 이상 만들면 반려)
1. **좌측 장면 리스트**: 이름 + 상태 뱃지(회색 빈칸/파랑 조립됨/초록 합격/빨강 불합격) + 상단 진행률(합격 n/전체)
2. **우측 작업 영역**: 선택 장면의 슬롯 A·B·C 편집칸 3개 + [조립] [복사] 버튼
   + 조립 결과 미리보기 + 판정 5항목 체크 + [합격][불합격] 버튼 (기존 v2 로직 그대로)
- 저장: 슬롯 편집·상태 변경은 즉시 localStorage + [JSON 내보내기] 버튼으로 scenes-catalog.json 갱신본 다운로드

## C. 골격 (변형 절대 금지)
- v2에 내장된 HEAD/STYLE/NEVER/조립 문법을 그대로 사용한다 — 단이 스킬 §2-11이 정본.
- 코다리가 골격 문장을 "개선"하는 순간 반려. 슬롯 3개 외에는 손대지 않는다.

## D. 금지 (작업대 비대화 방지 — 지난번 36KB 사고 재발 금지)
- 검색·필터·정렬·차트·통계·탭 추가 금지. 기능은 B의 목록이 전부다
- 외부 라이브러리 금지, 서버 통신 금지 (로컬 파일 + localStorage만)
- 라이브 파일(demo·index 등) 접근 금지 / Python 금지

## E. 완료 판정 (관찰 가능 기준)
1. 파일 열면 좌측에 8장면이 뜨고, 범선 클릭 시 슬롯이 채워진 상태로 보인다
2. [조립]→[복사] 하면 클립보드에 골격 v3 전문이 들어간다 (grep 확인: HEAD 문장 일치)
3. 판정 체크→[합격] 시 리스트 뱃지가 초록으로 바뀌고 새로고침 후에도 유지된다
4. 390px 스크린샷 첨부 (좌측 리스트가 상단 접이식으로 변해도 무방)
5. grep -c "scenes-catalog" 장면작업대.html ≥1 원문 출력
