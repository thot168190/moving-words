## 왜 되돌리는가 — 기계로 센 사실만

### ① 매칭표의 레벨 표기가 44% 어긋나 있다

「레벨1 = 초등800 / 레벨2 = 중등1200(마스터리스트)」 기준으로 `_작업/매칭표_정본.csv` 1,200행 검사:

| | 행수 |
| :--- | ---: |
| 기준 일치 | 669 |
| **중등어인데 레벨1로 적힘** | **512** |
| **초등어인데 레벨2로 적힘** | **19** |
| 어긋남 | **531 (44%)** |

실제 예 — `dolphin`(돌고래)이 레벨2, `reflect`(반사하다)가 레벨1. 거꾸로다.
`tower` `shine` `shore` `bay` `coast` `brain` `lawyer` `soldier` 등 512개가 중등어인데 레벨1에 있다.

**표가 어긋나 있었다. 코다리는 표대로 정확히 부었다. 코다리 잘못이 아니다.**

### ② 좌표가 그림과 무관하다

157편의 좌표점 1,077개 중 **서로 다른 값이 533개뿐**이다. 절반이 재사용이다.

- `[78,28]` 이 **19편**에서 동일하게 쓰임
- `[76,26]` 16편 · `[48,42]` 15편 · `[32,28]` 15편
- **12편은 좌표 세트가 통째로 같음** — 예: `4-05 4-06 4-07 4-09 4-11 12-05 12-07 12-09` 여덟 편이
  `[[50,45],[75,30],[25,75],[75,75],[28,30],[50,80]]` 로 완전히 동일

그래서 대표님이 보신 대로 **`deck`이 하늘에 뜨고 고래 그림에서 `ocean`이 고래 몸통에 찍힌다.**
격자값을 만들어 전 편에 복사한 것이다. 그림을 보고 찍은 게 아니다.

### ③ UI 이슈 (코다리 몫)

매칭표는 편당 단어가 **1~9개 가변**인데 앱은 `levelOneWords` 4 + `levelTwoWords` 4 **고정**이다.
`1-04 고래`는 표에서 레벨1이 `wave` 하나뿐이라 그대로 부으면 카드가 한 장만 뜬다.
**목록 UI를 가변 개수로 확장해야 한다.** 이건 로부장이 손대지 않는다.

## 다음 공정 — 순서와 담당

| 단계 | 할 일 | 담당 | 예상 |
| :--- | :--- | :--- | :--- |
| **1** | 원상복구 (위 명령) | 코다리 | 1분 |
| **2** | 레벨 보정표 생성 — `매칭표_레벨보정.csv` | 로부장 | 10분 |
| **3** | 목록 UI 가변 개수 확장 | **코다리** | — |
| **4** | 좌표 전면 재작업 (157편 ≈ 1,100점) | 로부장 | 챕터당 20분 |
| **5** | 챕터별 검증표 확인 → 승인 | 대표님 | — |
| **6** | 확정본 주입 | 로부장 | — |

**2단계를 3·4단계보다 먼저 하는 이유:** 레벨이 확정돼야 편당 단어가 정해지고,
그래야 좌표를 한 번만 찍는다. 순서를 바꾸면 두 번 일한다.

### 2단계 규칙 (로부장이 지킬 것)

- `_작업/매칭표_정본.csv` **원본은 건드리지 않는다.** 보정본을 새 파일로 낸다.
- 판정 규칙은 한 줄뿐이다 — **마스터 1200에 있으면 레벨2, 없으면 레벨1.**
  단어를 더하거나 빼지 않는다. 레벨 글자만 바꾼다.
- 보정 결과 편당 개수가 4+4에서 벗어나는 편 목록을 함께 낸다 (3단계 UI 작업 근거).

### 4단계 규칙

- 포스터를 **직접 열어 보고** 좌표를 찍는다. 격자값 복사 금지.
- 챕터 하나 끝날 때마다 **그림 위에 점이 찍힌 검증표(HTML)** 를 대표님께 드린다.
- 대표님 승인 전에는 다음 챕터로 넘어가지 않는다.
- 좌표를 못 정하는 단어(그림에 없는 추상어)는 **비워두고 보고**한다. 억지로 찍지 않는다.
