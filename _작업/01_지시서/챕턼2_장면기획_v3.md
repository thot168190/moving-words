## 왜 「몸과 감각」이 아닌가

목차 §2-12의 2장은 「몸과 감각」이다. **지금 골격으로는 못 만든다.**

| | |
|---|---|
| 골격 v3는 | 자연·풍경 도감용이다. 산호·바다·돛단배가 전부 그것이다 |
| 「몸과 감각」은 | `brain` `jaw` `nerve` `muscle` — 한 그림에 넣으면 **해부도**가 된다 |
| 해부도는 | 챕터1에서 이미 실패한 것이다 (`dorsal fin` `rigging` `porthole`) |

**인물·신체 골격이 따로 필요하다.** 그건 오늘 안 만든다. 되는 것부터 찍는다.
목차 순서는 나중에 재배열하면 된다 — 1장도 이미 「나침반」에서 바다로 바뀌었다.

**챕터2 = 「땅과 하늘」.** 바다에서 내려 육지를 걷고 마지막에 하늘로 뜬다. 항해 세계관과 맞는다.
