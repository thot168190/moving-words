## 1. 대표님이 먼저 해야 하는 것 (코다리 착수 전 필수)

코다리는 이 값 없이는 시작할 수 없다. **없으면 멈추고 보고한다.**

1. 포트원 콘솔(`admin.portone.io`) 로그인
2. **결제 연동 → 연동 정보** 에서 **V2** 선택
3. **테스트 채널** 추가 — KPN(한국결제네트웍스), 카카오페이 각각
4. 다음 2개를 받아 로부장에게 전달

```
storeId    = store-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
channelKey = channel-key-xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

> ⚠️ 이 두 값은 **공개키**다. 프론트엔드에 들어가도 되는 값이다.
> **API Secret(V2 시크릿)은 절대 프론트에 넣지 않는다.** 코다리에게도 주지 않는다.

## 2. 코다리 작업 (값 받은 뒤)

### 2-1. SDK 설치
```bash
npm i @portone/browser-sdk
```
→ `package.json` 의 dependencies에 추가된 줄을 **출력 원문으로** 보고.

### 2-2. 설정 파일 신규 생성 — `src/lib/portone.ts`

```ts
// 포트원 V2 설정
// storeId / channelKey 는 공개키다. API Secret은 여기 넣지 않는다.
export const PORTONE_CONFIG = {
  storeId: import.meta.env.VITE_PORTONE_STORE_ID || '',
  channelKey: import.meta.env.VITE_PORTONE_CHANNEL_KEY || '',
  redirectUrl: `${window.location.origin}/payment/success`,
};

export function generatePaymentId(): string {
  return `payment-${Date.now()}-${Math.random().toString(36).slice(2, 10)}`;
}
```

### 2-3. 버튼 컴포넌트 신규 생성 — `src/components/payment/PortOneCheckoutButton.tsx`

**기존 `TossCheckoutButton.tsx` 를 지우지 않는다. 새 파일로 만든다.**
버튼의 **겉모습(className·문구·아이콘)은 TossCheckoutButton과 한 글자도 다르지 않게 복사**한다.
바뀌는 것은 호출부뿐이다.

```ts
import * as PortOne from '@portone/browser-sdk/v2';
import { PORTONE_CONFIG, generatePaymentId } from '../../lib/portone';

const response = await PortOne.requestPayment({
  storeId: PORTONE_CONFIG.storeId,
  channelKey: PORTONE_CONFIG.channelKey,
  paymentId: generatePaymentId(),
  orderName: product.name,
  totalAmount: product.price,
  currency: 'CURRENCY_KRW',
  payMethod: 'CARD',
  redirectUrl: PORTONE_CONFIG.redirectUrl,
});
if (response?.code !== undefined) {
  onError?.(response.message);
}
```

> 📌 **파라미터 이름은 반드시 포트원 V2 공식 문서와 대조한다.**
> https://developers.portone.io/opi/ko/integration/start/v2/checkout
> 위 예시와 문서가 다르면 **문서를 따르고, 다른 점을 보고**한다. 추측으로 고치지 않는다.

### 2-4. `.env.example` 에 항목 추가 (`.env` 는 건드리지 않는다)

```
# ── 포트원 V2 ──
# admin.portone.io → 결제연동 → 연동 정보(V2)
VITE_PORTONE_STORE_ID=
VITE_PORTONE_CHANNEL_KEY=
```

### 2-5. `src/App.tsx` 교체 — **11행과 662행 두 곳만**

- 11행 `import TossCheckoutButton ...` → **아래에 PortOne import 한 줄 추가** (Toss import는 그대로 둔다)
- 662행 `<TossCheckoutButton` → `<PortOneCheckoutButton` 으로 **태그 이름만** 교체
- `product` `onError` 등 **props는 손대지 않는다**

### 2-6. 빌드 확인
```bash
npm run build
```
→ 성공/실패 **출력 원문 그대로** 보고. 타입 에러가 나면 고치려 하지 말고 **에러 전문을 붙여서 보고**한다.
