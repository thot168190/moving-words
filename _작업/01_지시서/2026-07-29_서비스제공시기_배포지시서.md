# 코다리 지시서 — 「서비스 제공 시기」 문구 배포

> 발신: 로부장 | 2026-07-29 | **우선순위: 최상 (카카오페이 심사 보완)**
> **소스 수정은 로부장이 이미 끝냈다. 빌드·배포·검증만 하라.**

---

## 0. 실행 규칙

1. **묻지 말고 끝까지 완주하라.** 단계마다 승인 요청 금지
2. **소스 코드를 수정하지 마라.** 이번 작업은 빌드·배포·검증뿐이다
3. "완료했습니다"는 근거가 아니다. **§3 검증 출력 원문**만 인정한다
4. 명령은 `&&` 로 한 줄에 묶어서 실행하라

---

## 1. 왜 하는가

카카오페이 연동 심사에서 **「서비스 제공 기간 누락」** 보완 요청이 왔다.
전자상거래법상 **재화등의 공급시기** 표기이며, 없으면 심사가 반려된다.

로부장이 아래 2개 파일을 이미 고쳤다. **되돌리지 마라.**

| 파일 | 무엇이 들어갔나 |
|---|---|
| `src/App.tsx` | 결제 버튼 아래에 `서비스 제공 시기: 결제 완료 즉시 이용 가능 (구매 후 기간 제한 없이 이용)` |
| `public/terms.html` | 제3조에 서비스 제공 시기 항목 추가 |

타입 검사 통과했다 (`npx tsc --noEmit` 오류 0건).

---

## 2. 할 일

```bash
npm run build && cp -R dist/* dist-final/ && npx gh-pages -d dist-final
```

배포 후 `dist-final/assets/` 에 **구버전 JS·CSS가 남으면 `_to_delete/` 로 옮겨라. 삭제하지 마라.**

---

## 3. 자가검증 (출력 원문 없으면 반려)

배포 후 2~3분 기다렸다가 아래를 **그대로 실행**하고 출력 전체를 붙여라.

```bash
echo "=== [A] 서비스 제공 시기 ==="
curl -sL https://inkword.site | grep -c "서비스 제공 시기"
curl -sL https://inkword.site/terms.html | grep -c "서비스 제공 시기"

echo "=== [B] 기존 표기 유지 ==="
curl -sL https://inkword.site | grep -c "7일 이내 전액 환불"
curl -sL https://inkword.site | grep -c "105동 603호"
curl -sL https://inkword.site | grep -c "010-2058-9900"

echo "=== [C] 게이팅 유지 ==="
curl -sL https://inkword.site/learning/index.html | grep -c "FREE_SCENES=3"
curl -sL https://inkword.site/learning/index.html | grep -c "gate-modal"

echo "=== [D] 번들 정합 ==="
grep -o 'assets/index-[A-Za-z0-9_-]*\.\(js\|css\)' dist-final/index.html
ls dist-final/assets/
```

### 합격 기준

| 항목 | 기대값 |
|---|---|
| `[A]` 랜딩 `서비스 제공 시기` | **1 이상** |
| `[A]` 약관 `서비스 제공 시기` | **1 이상** |
| `[B]` `7일 이내 전액 환불` | 1 이상 |
| `[B]` `105동 603호` | 1 이상 |
| `[B]` `010-2058-9900` | 1 이상 |
| `[C]` `FREE_SCENES=3` | **2** |
| `[C]` `gate-modal` | **3** |
| `[D]` `dist-final/assets/` 의 js·css | **각 1개만** |

**`[A]`가 랜딩에서 0이면 프리렌더 문제다.** 그때는 `index.html` 안의 `<div id="root">` 프리렌더 블록에도 같은 문구를 넣어야 하니 로부장에게 보고하라. **임의로 손대지 마라.**

## 4. 금지

1. 소스 코드 수정 금지 (프리렌더 포함)
2. 카피 한 글자도 고치지 마라
3. `_to_delete/` 안의 파일 삭제 금지
4. Netlify 배포 금지. **GitHub Pages(`gh-pages` 브랜치)가 정본**
5. Python 실행 금지. node 또는 셸을 써라
6. `FREE_SCENES=3` 숫자 변경 금지
