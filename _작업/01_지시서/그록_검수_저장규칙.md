# 그록 1200 검수 — 저장 규칙 (반복 작업 매뉴얼)

## 매 회차 흐름 (3단계, 대표님 5분)

### 1) 지시서 복사 → 그록에 붙여넣기
```
_작업/01_지시서/그록_1200검수_N회차.md
```
파일 열고 ⌘A → ⌘C → 그록에 붙여넣기. 단어 100개가 지시서 안에 이미 들어 있음.

### 2) 결과 저장
그록이 낸 표를 그대로 복사해서 아래 위치에 **.md 파일**로 저장.

```
_작업/02_보고서/그록검수/N회차_결과.md
```

예: `_작업/02_보고서/그록검수/2회차_결과.md`

> 파일명 규칙을 지켜야 나중에 로부장이 자동으로 찾아 반영함.

### 3) 로부장에게 알리기
"N회차 끝났어" 한마디면 됨. 로부장이:
- `data/1200_마스터리스트_v1.csv` 의 **검수** 칸에 O / X(사유) 반영
- 뜻이 비어 있던 칸도 채움
- X 나온 단어의 **교체어 후보**를 찾아 제시
- 다음 회차 지시서 생성

## 저장 위치 정리

| 무엇 | 어디 |
|---|---|
| 지시서 (로부장이 만듦) | `_작업/01_지시서/그록_1200검수_N회차.md` |
| 그록 결과 (대표님이 저장) | `_작업/02_보고서/그록검수/N회차_결과.md` |
| 정본 데이터 (로부장만 수정) | `data/1200_마스터리스트_v1.csv` |

**⚠️ CSV는 대표님이 직접 열어 고치지 마십시오.** 엑셀로 열면 한글이 깨지고 열이 밀립니다.
반영은 로부장이 합니다.
