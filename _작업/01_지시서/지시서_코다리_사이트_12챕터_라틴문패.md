# 코다리 지시서 — 사이트 탐험지도 12챕터 라틴 문패

발행: 2026-08-09  
발주: 대표님  
대상: `public/learning/index.html`의 탐험지도 챕터 문패 12개

## 0. 이번 작업의 뜻

사이트 탐험지도에 표시된 기존 한글 챕터 이름을 지우는 작업이 아니다.

각 지점에 아래 두 줄을 **항상 동시에** 표시한다.

```text
INVENTIO
인벤티오 · 세상을 발견해요
```

- 첫 줄: 멋있고 짧은 라틴 문패
- 둘째 줄: 아이가 소리 내어 읽을 수 있는 한글 발음 + 쉬운 뜻
- 라틴어 어원 수업처럼 길게 설명하지 않는다.
- 아이가 지도를 보는 즉시 읽고 뜻을 알 수 있어야 한다.

## 2. 수정 범위

수정 허용 파일:

```text
public/learning/index.html
```

현재 코드의 다음 부분만 다룬다.

- `chapters`
- `chapterEnglish` 또는 이를 대체하는 라틴 문패 배열
- 읽는 법·쉬운 뜻 배열
- `chapterGrid.innerHTML`의 문패 마크업
- 지도 문패에 직접 적용되는 `.label-*`, `.chapter-grid .chapter-card h3` 관련 CSS
- 접근성용 `aria-label`

백업 HTML은 수정하지 않는다.

## 3. 표시 규칙

### 필수

1. `CHAPTER 01` 배지는 그대로 둔다.
2. 그 아래 라틴 문패를 가장 크게 표시한다.
3. 바로 아래에 `읽는 법 · 쉬운 뜻`을 라틴 문패보다 작게 표시한다.
4. 두 줄은 마우스를 올리지 않아도 항상 보여야 한다.
5. 호버·키보드 포커스·터치 상태에서도 어느 한 줄이 사라지면 안 된다.
6. 문패의 중심은 현재 각 원형 학습 지점의 중심을 유지한다.
7. 잠금 지점의 투명도와 1장 활성 원은 유지한다.
8. 모바일 가로 스크롤 지도에서도 12개 문패가 잘리지 않아야 한다.

### 권장 마크업

```html
<h3>
  <span class="label-latin" lang="la">INVENTIO</span>
  <span class="label-guide" lang="ko">인벤티오 · 세상을 발견해요</span>
</h3>
```

기존 `.label-ko`와 `.label-en`을 겹쳐 놓고 호버 시 교대하는 방식은 제거한다.

### 크기 원칙

- 라틴 문패: 현재 한글 제목과 비슷한 시각적 무게
- 한글 안내: 라틴 문패의 약 55~65%
- 둘째 줄은 굵기를 한 단계 낮춘다.
- 흰 외곽선 또는 그림자 처리는 지도 위 가독성 확보에 필요한 만큼만 유지한다.
- 문패 폭을 키워 지점끼리 충돌시키지 않는다.

## 4. 절대 변경 금지

- `assets/chapter-adventure-map-v4.png` 이미지
- `chapterSpots` 12개 좌표와 순서
- 챕터 번호
- 열림·잠김 판정
- 클릭 및 키보드 동작
- 결제 게이트
- 학습 영상·단어·장면 데이터
- localStorage 키와 학습 진도
- 홈·가격·약관 등 다른 페이지
- 새 지도 이미지 생성
- 백업 파일 생성 또는 기존 백업 수정

이번 작업은 **지도 문패의 글자 표시만** 바꾼다.

## 5. 접근성

각 지점의 `aria-label`에는 다음 정보가 모두 포함돼야 한다.

```text
챕터 번호, 라틴 문패, 한글 읽는 법, 쉬운 뜻, 열림 또는 잠김 상태
```

예:

```text
챕터 1, INVENTIO, 인벤티오, 세상을 발견해요, 학습 가능
```

## 6. 검증

### 기계 검증

1. `npm run build` 통과
2. 라틴 문패 12개가 원문에 각각 정확히 1회 이상 존재
3. 한글 읽는 법 12개가 원문에 각각 정확히 1회 이상 존재
4. `chapterSpots` 변경 없음
5. 지도 이미지 경로 변경 없음
6. `label-ko`/`label-en` 호버 교대 규칙이 지도 문패에 남아 있지 않음

### 화면 검증

다음 두 장을 제출한다.

- 데스크톱: 지도 12개 전체가 보이는 화면
- 모바일 390px: 가로 스크롤 첫 구간과 중간 또는 끝 구간

눈으로 확인할 항목:

- 라틴어와 한글 안내가 동시에 보임
- 글자 겹침 없음
- 지점 간 문패 충돌 없음
- 라틴어가 지나치게 크지 않음
- 한글 안내가 숨기듯 작지 않음
- 호버하지 않아도 읽을 수 있음
- 첫 챕터 클릭 정상
- 잠긴 챕터 클릭 동작 기존과 동일
