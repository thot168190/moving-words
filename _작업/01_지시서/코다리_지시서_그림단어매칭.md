# 코다리 지시서 — 그림과 단어 매칭

발행: 로부장
도구: `_작업/scene_tool.py`
**이 문서는 매칭 하나만 다룬다.** 파일 정리·배포는 `공통지시서_영상매칭_파이프라인.md`에 있다.

---

## 0. 이 작업이 왜 제일 중요한가

이 제품의 핵심은 **"그림이 글자로 변신한다"**는 것 하나다.
단어가 그림에 없으면 그 편은 그냥 예쁜 그림이지 단어장이 아니다.

이미 사고가 두 번 났다.

| 사고 | |
|---|---|
| 「자전거와 수레」 그림에 `motor`·`vehicle` | 그림에 모터도 차량도 없다 |
| 「머그잔과 휴식」에 `joy`·`delight` 둘 다 「기쁨」 | 같은 화면에 뜻이 같은 단어 두 개 |

**둘 다 그림을 안 보고 단어를 골라서 생긴 일이다.**

---

## 1. 한 편 처리 순서

### STEP 1 — 그 챕터에 남은 단어를 본다

```bash
python3 _작업/scene_tool.py remain 8
```

갈래별로 아직 안 쓴 단어가 나온다. **여기 없는 단어는 절대 쓰지 마라.**
- 정본 1200 밖 단어 → 쓰면 진도에 안 잡힌다
- 이미 다른 편에 쓴 단어 → 같은 단어가 두 편에 뜬다

### STEP 2 — 포스터를 열고 무엇이 있는지 먼저 적는다

**단어 목록을 보기 전에** 그림부터 본다. 순서가 중요하다.
목록을 먼저 보면 "이 단어 넣을 만한가?" 하고 그림에서 억지로 찾게 된다.

포스터를 열고 보이는 것을 그대로 적어라.

```
ch10_04 포스터
  왼쪽    굽은 도로, 점선 차선
  왼쪽 위  굴뚝 2개, 하나에 주황 불꽃, 연기
  가운데   공장 스카이라인, 굴뚝들
  오른쪽 아래 얼음 덩어리, 녹은 물웅덩이
  전체    푸른 회색 톤, 새벽 느낌
```

**포스터를 못 열면 여기서 멈추고 보고하라.** 추측으로 고르지 마라.

### STEP 3 — 적어둔 것과 남은 단어를 맞춘다

**그림 → 단어** 방향으로 간다. 반대로 하지 마라.

| 판정 | 기준 | 예 |
|---|---|---|
| **넣는다** | 그림에 **사물로 보인다** | 얼음 → `freeze` · 굴뚝 → `factory` |
| **넣는다** | 그림이 **동작을 보여준다** | 녹는 물 → `melt` · 피어오르는 연기 → `steam` |
| **조건부** | 그림 전체의 **상태·분위기**이고, 가리킬 자리가 있다 | 하늘 → `climate` · 굴뚝과 얼음 사이 → `temperature` |
| **뺀다** | 눈에 없고 가리킬 자리도 없다 | 공장 그림에 `budget` |

**8개가 안 되면 8개만 넣지 마라. 되는 만큼만 넣고 보고하라.**
억지로 채운 한 개가 그 편 전체를 망친다.

### STEP 4 — 뜻을 붙인다

**뜻은 사전이 아니라 그림이 정한다.**

| 단어 | 그림 | 뜻 |
|---|---|---|
| `patient` | 쉬고 있는 환자 | **환자** (「참을성 있는」 아님) |
| `post` | 궁전 근위병 | **지키는 자리** (「기둥」·「우편」 아님) |
| `gate` | 공항 | **탑승구** (「문」 아님) |

**뜻이 영어 단어보다 어려우면 안 된다.** 대표님 지시다.

| 나쁨 | 좋음 |
|---|---|
| marvel = 경이 | **놀라운 것** |
| comfort = 위안 | **편안함** |
| panic = 공황 | **겁에 질림** |
| motor = 모터 | **모터(전동기)** |

- 중등 수준 · 한자어 피하기 · 영어를 한글로만 옮기지 말기
- **같은 편 안에서 뜻이 겹치면 안 된다** — `joy`와 `delight`를 둘 다 「기쁨」으로 넣은 사고가 있었다

### STEP 5 — 레벨1 · 레벨2로 나눈다

```
levelOne  4개  ← 퀴즈가 이 4개를 쓴다 (코드가 slice(0,4))
levelTwo  4개  ← 나머지
```

**레벨1에는 그 장면을 바로 읽는 쉬운 단어**를 넣는다. 사물 이름이 대부분이다.
**레벨2에는 한 단계 깊은 어휘** — 동작·상태·추상어가 온다.

`_작업/1200_레벨태그_v3.csv` 의 `레벨` 칸을 참고하라. 다만 그림이 우선이다.

### STEP 6 — 좌표를 찍는다

포스터를 보며 각 단어가 가리키는 것의 위치를 **가로%(왼쪽 0 → 오른쪽 100), 세로%(위 0 → 아래 100)** 로 적는다.

| 규칙 | |
|---|---|
| x, y 는 **8~92** | 가장자리에 붙으면 글자가 잘린다 |
| 같은 레벨 안 거리 **18 이상** | 글자가 포갠다 |
| **좌우대칭·격자 금지** | `[[20,20],[80,20],[20,80],[80,80]]` 같은 모양이 나오면 그림을 안 본 것이다 |
| 주인공을 가리지 않는다 | 고래 얼굴, 얼음 덩어리 같은 중심은 비운다 |
| 긴 단어는 중앙 쪽으로 | `temperature`는 가로로 길게 뻗는다 |

**추상어는 그 뜻이 가장 잘 드러나는 곳에** 찍는다. `climate`는 하늘, `flame`은 모닥불 위, `aloud`는 이야기하는 쪽.

**최상위 기준은 대표님 지시다.**

> **"정상적으로 보이느냐가 기준이다. 규칙을 다 지켜도 화면에서 어색하면 실패다."**

다 찍은 뒤 그림을 다시 열어 자문하라 — 주인공 가림 / 글자 부딪힘 / 한쪽 쏠림 / 가장자리 잘림 / 빈 데 혼자 뜸.

### STEP 7 — JSON 한 장으로 적는다

`_작업/새편/ch10_05.json`

```json
{
  "chapter": 10,
  "n": "05",
  "title": "녹는 얼음과 공장",
  "sub": "온도가 오르는 자리",
  "video": "ch10/ch10_05.mp4",
  "img":   "ch10/ch10_05-poster.jpg",
  "levelOne": [ ["freeze","얼다",[72,65]], ["melt","녹다",[52,82]],
                ["factory","공장",[52,48]], ["steam","김",[32,18]] ],
  "levelTwo": [ ["steel","강철",[18,48]], ["degree","도",[75,42]],
                ["climate","기후",[52,22]], ["temperature","온도",[22,72]] ]
}
```

**좌표를 단어에 붙여 쓴다.** 배열을 따로 두면 순서가 어긋나 엉뚱한 자리에 뜬다.

## 2. 검사하고 넣는다

```bash
python3 _작업/scene_tool.py check _작업/새편/ch10_05.json    # 반드시 통과
python3 _작업/scene_tool.py add   _작업/새편/ch10_05.json    # 5배열 자동
python3 _작업/scene_tool.py verify
```

`check`가 잡는 것 — 정본 1200 밖 · 이미 쓴 단어 · 뜻 중복 · 뜻 빈칸 · 좌표 범위 · 좌표 겹침 · 좌우대칭 · 파일 존재 · 파일명 특수문자 · 편 중복

**★ 하나라도 뜨면 넣지 마라.**

---

## 3. 자주 나는 실수 — 이것만 안 하면 된다

| 실수 | 결과 |
|---|---|
| 단어 목록을 먼저 보고 그림에서 찾기 | 그림에 없는 단어가 들어간다 |
| 8개를 채우려고 억지로 넣기 | 「자전거와 수레」의 `motor` 사고 |
| 사전 뜻을 그대로 쓰기 | `patient`가 「참을성 있는」이 된다 |
| 한자어 뜻 | 「경이」「위안」「공황」 — 뜻칸이 벽이 된다 |
| 같은 편에 비슷한 뜻 두 개 | `joy`·`delight` 둘 다 「기쁨」 |
| 좌표를 감으로 찍기 | 대칭·격자가 나온다. 47편이 그렇게 망가졌다 |
| 좌표를 단어보다 적게 넣기 | **그 편이 통째로 안 열린다** |
| 5배열을 손으로 맞추기 | `scene_tool.py add`를 써라 |

## 4. 보고 양식

```
[편]     ch__-__ 제목 __
[그림]   포스터에 보이는 것 __ (한 줄)
[단어]   넣은 것 __개 · 그림에 없어서 뺀 것 __ (단어와 이유)
[뜻]     어려워서 다시 잡은 것 __
[레벨]   L1 __개 / L2 __개
[좌표]   __개 · 대칭 나와서 다시 찍은 것 __
[눈검사] 5개 자문 통과 __ / 어색해서 다시 찍음 __
[검사]   check __ / add __ / verify __ (출력 그대로)
[특이]   배정이 이상해 보이는 단어 · 그 밖에
```

## 5. 판정은 대표님이 한다

코다리가 정하지 않는 것 —

- 그림 자체의 합격·불합격
- 뜻의 최종 확정
- 그림에 애매하게 걸치는 단어를 넣을지 말지 (**애매하면 빼고 보고하라**)

**애매한 것을 넣는 것보다 빼고 보고하는 쪽이 항상 낫다.** 빼면 나중에 넣으면 되지만, 틀리게 넣으면 좌표까지 다시 짜야 한다.
