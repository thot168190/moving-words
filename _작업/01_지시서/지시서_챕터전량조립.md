# 코다리 지시서 — 챕터 전량 채우기 (Flow 크레딧 소진 작전)

> 발신: 로부장 | 실행: 코다리 (실패 시 동일 지시서를 코덱스에)
> 목표: 65갈래 전체를 장면 프롬프트로 조립해 대표님이 Flow에 복붙만 하면 되는 상태로 만든다.
> ⚠️ 창작 금지. 아래 정본 파일과 골격의 슬롯만 채운다. 골격 문장 한 글자 변형 = 반려.

## 정본 입력 (전부 _작업/ 안)
- `all1200.txt` — 단어 정본 1200. **장면 단어는 여기서만 꺼낸다. 밖의 단어 = 즉시 반려**
- `1200_레벨태그_v3.csv` — 단어별 레벨1/레벨2
- `1200_분류.json` — 65갈래
- `장면작업대.html` — 골격 v3 전문(HEAD/드로잉/채색/움직임/STYLE/NEVER) + 합격 견본(범선) 내장
- `qc_scene.py` — 기계 검문소 (로부장 작성. **수정 절대 금지**)

## 작업 규칙
1. 갈래마다 장면 1~2개 설계. 장면당 단어 5~10개(가변), **레벨2 비율 최소 1/3**
2. 프롬프트 = 골격 v3에 슬롯 3개만 삽입:
   - A 피사체 3~5 (프레임에 잘리는 요소 1 + 스케일 대비 1 필수)
   - B 색 3~4 구체 명명 (여름 채도, 원색 금지)
   - C 마지막 2.5초 와 요소(빛의 사건 또는 살아있는 동작 1~2)
3. 저장 형식: `_작업/scenes/씬번호_갈래.json`
   `{"name":"장면이름","갈래":"...","words":[...],"prompt":"완성 프롬프트 전문"}`
4. 전 장면 조립 후 `python3 qc_scene.py scenes/` 실행 → **반려 0이 될 때까지 스스로 수정**
   (⚠️ 파이썬이 세그폴트 나면 스크립트 로직을 그대로 손으로 검사하고 그 사실을 보고에 명시)
5. 챕터 리듬: 각 갈래 첫 장면 = 와(경이), 그 외 = 쉼. 견본은 작업대의 범선 프롬프트

## 금지
- all1200.txt 밖의 단어 사용 / 골격·STYLE·NEVER 문장 수정 / qc_scene.py 수정
- 새 골격 발명, 새 미학 제안 (그건 로부장 관할)
- 라이브 파일(index 등) 접근

## 완료 판정
1. `ls scenes/ | wc -l` ≥ 65 원문
2. `qc_scene.py` 출력 원문 — 전 장면 [통과]
3. 사용 단어 합계와 미사용 단어 수 보고 (1200 커버리지 %)

## 보고 양식
ls 원문 + QC 출력 원문 + 커버리지 %. "완료했습니다" 한 줄 보고는 미완료로 간주한다.

## 개정 2 (2026-07-30) — 수신: 코덱스 (코다리는 본 공정에서 해임)

코다리 산출물 2회 반려 사유 (재발 = 즉시 반려):
1. 피사체를 사물로 번역하지 않고 단어를 문장에 기계 치환 ("a stylized since" 같은 비문)
2. 문장 골조 하나에 단어만 갈아끼우는 매드립스 × 200
3. 65갈래 파괴 (알파벳순 6개 썰기, "Category 62")
4. 검사 통과가 목적이 된 필러 단어 돌려막기

qc_scene.py는 v3다. 위 수법은 전부 기계 반려된다. 추가 준수:
- scene JSON의 "갈래"는 1200_분류.json의 실제 갈래명. 장면 단어는 그 갈래에서, 레벨 비율 맞출 때만 타 갈래 손님 단어 최대 2개
- 피사체는 단어의 '뜻'을 눈에 보이는 장면으로 번역한다.
  예: promote/wage/lend(돈 갈래) → 시장 좌판, 동전을 세는 손, 저울… 단어 철자가 아니라 뜻이 그림이 된다
- 추상어·기능어가 낀 장면은 도해적 연출(사물 간 관계·위치·크기)로 뜻을 시각화
- 골조 문장은 장면마다 처음부터 새로 쓴다. 두 장면이 같은 골조면 둘 다 반려된다
- 견본: 장면작업대.html 내 범선 프롬프트가 유일한 품질 기준
