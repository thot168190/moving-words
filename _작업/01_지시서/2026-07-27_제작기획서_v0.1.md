## 1. 한 단어 = 무엇인가

> **8초짜리 영상 한 편.**
> 흰 화면에서 선이 그려지고 → 색이 올라오고 → **동작이 일어난다.**
> 그 동작이 곧 그 구동사의 뜻이다.

288개 단어 = 288편.

---

## 2. 8초 안의 구성 (고정)

| 시간 | 무슨 일 | 이유 |
|---|---|---|
| **0 – 3.5s** | 흰 화면에 선이 한 획씩 그려진다 | 제품 헌법 1조. 그려지는 과정이 제품 |
| **3.5 – 5.5s** | 수채가 층층이 올라온다 | 전 획 완주 후에만 채색 |
| **5.5 – 8s** | **동작이 일어난다** | **여기가 단어의 뜻.** 이 2.5초가 제품의 심장 |

- 카메라 고정. 8초 한 컷.
- 첫 프레임은 **완전한 빈 흰 화면**.
- 배경 순백 `#FFFFFF`.

**5.5–8초 칸만 단어마다 다릅니다.** 나머지는 전부 같은 골격입니다.

| 단어 | 5.5–8초에 일어나는 일 |
|---|---|
| `get on` | 사람이 계단을 올라 버스 안으로 들어간다 |
| `get off` | 사람이 버스 문에서 내려 보도에 발을 딛는다 |
| `pull up` | 차가 갓길로 미끄러져 멈춘다 |
| `hang up` | 손이 수화기를 내려놓는다 |
| `fill out` | 펜이 빈칸을 채워 나간다 |

## 3. 화면에 무엇이 보이나

**영상 안에는 그림만 넣습니다. 글자는 안 넣습니다.**

이유 세 가지입니다.

1. 글자를 영상에 구우면 **나중에 못 고칩니다.** 오타 하나에 8초를 다시 뽑아야 합니다
2. 영어·한국어·중국어로 확장할 때 **영상은 그대로 두고 글자만 바꾸면** 됩니다
3. 흰 배경이라 웹에서 글자를 얹기가 쉽습니다

```
[ 8초 영상 — 그림만 ]        ← AI가 만듦, 한 번 만들면 끝
        +
[ 단어 · 뜻 · 발음 ]          ← 웹에서 얹음, 언제든 수정 가능
```

**쇼츠도 같은 방식**입니다. 영상 위에 글자를 얹어서 내보냅니다.

## 4. 배경 — 흰 화면으로 갑니다

지금까지 두 가지 스타일이 섞여 있었습니다.

| | 콜로세움 (기존) | 만타레이 (대표님 프롬프트) |
|---|---|---|
| 배경 | 장면 안에 있음 | **순백** |
| 한 화면에 | 단어 여러 개 | **단어 하나** |
| 성격 | 풍경 | **도해** |

**구동사는 흰 화면 도해형이 맞습니다.**

- 구동사는 단어 하나당 동작 하나입니다. 풍경이 필요 없습니다
- 흰 여백이 있어야 글자를 얹습니다
- 배경을 안 그리니 **제작이 빠릅니다**
- 288개 스타일 통일이 훨씬 쉽습니다

**1200단어(미끼)는 장면형을 유지합니다.** 그건 한 그림에 단어 12개를 담아야 하니까요. 두 제품의 스타일이 다른 건 문제가 아니라 구분입니다.

## 5. 산출물 — 하나 만들면 셋이 나온다

| 쓰는 곳 | 규격 | 만드는 법 |
|---|---|---|
| **학습장** | 가로 16:9, 8초 | 원본 |
| **쇼츠** | 세로 9:16, 8초 | 원본을 세로로 재구성 + 글자 얹기 |
| **썸네일·포스터** | 정지 1장 | 영상 마지막 프레임 뽑기 |

영상 하나로 세 군데를 씁니다. 따로 안 만듭니다.

## 6. 제작 공정 (한 단어 기준)

```
① 프롬프트 조립        골격에 슬롯만 채움          로부장    2분
② 영상 생성            Flow (text-to-video)        대표님    1~3분
③ 판정                 동작이 읽히는가             대표님    30초
④ 압축                 학습장용으로 용량 줄이기    로부장    자동
⑤ 등록                 학습장에 붙이기             코다리    자동
```

**②③만 대표님 손이 갑니다.** 나머지는 자동입니다.

**하루 3개면 96일, 하루 10개면 29일.** 이건 ②의 속도에 달렸습니다.

## 7. 대표님이 정해 주셔야 하는 것 3가지

**① 8초가 맞습니까?**
- 8초: 그려짐 3.5 + 채색 2 + 동작 2.5. 지금 안
- 더 짧게(5~6초): 동작이 급해집니다. 대신 288개를 빨리 만듭니다
- 더 길게(10초): 여유롭지만 학습자가 지루해할 수 있습니다

**② 사람이 등장합니까?**
- 등장: `get on`, `sit down` 같은 몸동작 구동사에 자연스럽습니다. 대신 얼굴·비율이 매번 달라질 위험
- 손만: 손과 사물만 나옵니다. 통일이 쉽고 나라·인종 문제도 없습니다. 대신 `walk out` 같은 건 표현이 어렵습니다
- 혼합: 몸이 필요한 것만 사람, 나머지는 손

**③ text-to-video로 바로 갑니까, 이미지를 거칩니까?**
- 바로: 한 단계. 빠름. 대신 스타일이 288가지로 갈라질 위험
- 이미지 거침: 첫 프레임을 확정하고 영상을 뽑음. 통일되지만 두 단계
- **만타레이 프롬프트는 text-to-video로 저 결과가 나왔습니다.** 그렇다면 바로 가도 될 수 있습니다 — 몇 개 뽑아 보고 스타일이 흔들리는지 보면 답이 나옵니다
