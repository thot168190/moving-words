# 코다리 지시서 — 챕터 지도 서체만 정리

## 목적

챕터 지도 위의 `CHAPTER 01`, 라틴어 문패, 한글 읽는 법·뜻이 한 덩어리처럼 두껍게 겹쳐 보인다. 이미지 수정은 나중에 한다. 이번 작업은 **서체 위계와 가독성만 단정하게 정리**한다.

## 수정 파일

- `public/learning/index.html` 한 파일만 수정
- 대상 선택자:
  - `.chapter-grid .chapter-card small`
  - `.chapter-grid .chapter-card h3`
  - `.chapter-grid .chapter-card .label-latin`
  - `.chapter-grid .chapter-card .label-guide`
  - 위 선택자의 모바일 규칙

## 동결 — 건드리면 반려

- 지도 이미지와 이미지 경로
- 12개 문패의 위치 좌표 `chapterSpots`
- 라틴어·발음·한글 뜻 문구
- 챕터 배열과 잠금 상태
- 클릭, 이동, 학습 진도, `localStorage`
- 지도 크기·비율·스크롤 방식
- 지도 밖의 모든 화면과 서체

## 서체 정리 기준

### 1. 라틴어 문패

- `WantedSans` 사용
- 굵기 `700`; 현재처럼 지나치게 검고 뭉친 인상 금지
- 데스크톱 `clamp(21px, 1.55vw, 27px)`
- 자간 `0.045em`
- 행간 `1`
- 색상은 현재 짙은 남색 계열 유지
- 흰 외곽선은 `3px` 이내로 줄인다. 두꺼운 스티커·자막 효과 금지
- 그림자도 흰색 번짐 한 겹만 약하게 사용

### 2. 한글 읽는 법·뜻

- `WantedSans` 사용
- 굵기 `600`
- 라틴어의 약 `52%` 크기: `clamp(12px, .86vw, 15px)`
- 위 여백 `4px`
- 자간 `-0.015em`, 행간 `1.2`
- 라틴어보다 한 단계 옅은 남회색으로 낮춘다
- 흰 외곽선은 `2px` 이내
- 발음과 뜻은 한 줄 유지. 임의 줄바꿈 금지

### 3. CHAPTER 캡슐

- 현재 붉은 캡슐과 위치는 유지
- `Pretendard` 굵기 `700`
- 글자 크기 `clamp(9px, .68vw, 12px)`
- 자간 `0.12em`
- 캡슐이 라틴어보다 먼저 보이지 않도록 그림자와 굵기를 줄인다

### 4. 모바일

- 지도 가로 스크롤과 문패 좌표는 그대로 둔다
- 라틴어 `21px`, 한글 `12px`를 기준으로 시작
- 라틴어·한글·CHAPTER 캡슐이 서로 겹치지 않게 세 요소 사이 세로 간격만 조정
- 카드 폭이나 좌표를 움직여 해결하지 않는다

## 원하는 인상

- 1순위: 라틴어 문패
- 2순위: `읽는 법 · 쉬운 뜻`
- 3순위: CHAPTER 번호
- 굵은 게임 로고나 방송 자막이 아니라 **정돈된 모험 지도 문패**
- 새 글꼴 설치 금지. 현재 포함된 WantedSans와 Pretendard만 사용
