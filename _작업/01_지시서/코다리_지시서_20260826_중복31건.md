# 코다리 지시서 — 단어 중복 31건 정리 (2026-08-26)

## 0. 먼저 알아둘 것

**보고 전에 반드시 이것을 돌리고, 출력을 그대로 붙여서 보고할 것.**

```bash
python3 _작업/검증_전체.py
```

`node --check` 로는 부족하다. 오늘 소챕터 따옴표 사고가 그 증거다.
`let activeSubTab = all;` 은 **문법상 완전히 정상**이라 `node --check` 가 통과시킨다.
`all` 이라는 변수가 없다는 건 실행해야만 드러난다.
새 검증기의 2번 항목이 이것을 잡는다.

또 하나. 오늘 `renderSubTabs()` 안의 4곳만 고치고 `setupWorks()` 안의 3곳을 놓쳤다.
**같은 오류는 파일 전체에서 세어라.** 눈에 보이는 자리만 고치면 반드시 남는다.

## 1. 단어 중복 31건 — 같은 챕터에서 같은 단어가 두 번

같은 챕터를 학습하는 사람이 이미 배운 단어를 다시 만난다. 반드시 정리한다.


### ch5 — 2건


### 처리 원칙

- **먼저 나온 편(작은 번호)을 남기고, 나중 편의 것을 교체한다.**
- 교체할 단어는 **그 그림에 실제로 보이는 것**에서 고른다. 없으면 **빼고 개수를 줄인다.**
  개수를 억지로 채우지 않는다. 대표님 지시다 — *"레벨 1/2가 분명하지 않으면 그림에 있는 것만 해"*
- 넣기 전에 정본 1200 안에 있는지, 다른 챕터에서 이미 썼는지 확인한다.

```bash
python3 _작업/scene_tool.py remain 2     # ch2 에 남은 단어
python3 _작업/scene_tool.py free         # 어느 챕터에도 안 든 갈래
```

## 2. 좌표가 남는 편 12건

단어보다 좌표가 많다. **지금 화면은 깨지지 않지만** 정리해야 한다.

```
ch6_02  L1 4/5      ch6_06  L2 3/4      ch7_01  L1 3/4 · L2 2/4
ch7_02  L1 3/4      ch8_02  L1 3/4      ch10_01 L1 3/4
```

남는 좌표를 지워 단어 수와 맞춘다. **반대(단어 > 좌표)는 그 편이 통째로 안 열리므로 절대 만들지 말 것.**

`ch10_03` 은 레벨1이 2개뿐이라 퀴즈가 2문제로 끝난다. 그림을 보고 2개를 더 채우거나, 그대로 둘지 대표님께 여쭐 것.
