## 4. 작업 3 — 히어로 모바일 잘림 수정 (`src/components/HeroWords.tsx`)

### 원인
`.hw-word` 는 `left:50%` 로 배치되는데 이 좌표가 요소의 **왼쪽 끝**이다. 48px 폰트 × 9글자가 통째로 오른쪽으로 넘어간다. 키프레임이 `transform` 을 쓰고 있어 `translateX(-50%)` 를 얹을 수 없다 — 그래서 **`transform` 이 아니라 독립 CSS 속성 `translate`** 를 쓴다. 두 속성은 별개로 합성되므로 애니메이션과 충돌하지 않는다.

### 수정
`HeroWords.tsx` 의 `<style>` 블록(55~79행) 안에서 아래 3개 규칙만 교체한다. 나머지 키프레임·JSX는 손대지 마라.

**(1) `62~64`행 `.hw-word` 규칙을 교체**

찾을 것:
```css
        .hw-word { position: absolute; opacity: 0; white-space: nowrap;
          animation: hw-pop .5s cubic-bezier(.2,1.6,.4,1) forwards,
                     hw-out .6s ease forwards 9.8s; }
```
넣을 것:
```css
        .hw-word { position: absolute; opacity: 0; white-space: nowrap;
          translate: -50% -50%;
          max-width: 92vw; text-align: center;
          animation: hw-pop .5s cubic-bezier(.2,1.6,.4,1) forwards,
                     hw-out .6s ease forwards 9.8s; }
```

**(2) `68~72`행 모바일 폰트 크기 4줄을 교체**

찾을 것:
```css
        .hw-main-en { font-size: 48px; }
        .hw-main-ko { font-size: 20px; }
        .hw-sub-en { font-size: 32px; }
        .hw-sub-ko { font-size: 16px; }
```
넣을 것:
```css
        .hw-main-en { font-size: clamp(26px, 8.5vw, 48px); }
        .hw-main-ko { font-size: clamp(14px, 4vw, 20px); }
        .hw-sub-en { font-size: clamp(18px, 5.5vw, 32px); }
        .hw-sub-ko { font-size: clamp(12px, 3.2vw, 16px); }
```

**(3) `73~78`행 데스크톱 미디어쿼리는 그대로 둔다.** `min-width:768px` 에서 clamp 상한을 덮어쓰므로 데스크톱 크기는 변하지 않는다.

### 부작용 안내 (의도된 것)
`translate: -50% -50%` 로 `top`/`left` 가 요소의 **중심** 기준이 된다. 단어 5개가 각각 지정 좌표를 중심으로 놓이며, 이는 의도된 변경이다. 좌표값(`WORDS` 배열 9~13행)은 **수정하지 마라.**
