# 코덱스 지시서 — 홈 색 개편: 화이트 전환 (2026-07-31 대표님 확정)

> 확정 지침: "바탕은 화이트(순백). 그린은 숨통. 전부 딥그린은 오바." — 종이색·아이보리 아님, 그냥 화이트.
> 원칙: **화이트가 주인공, 딥그린은 악센트.**

## 색 체계 (홈/랜딩 한정)
1. **바탕**: 순백 `#FFFFFF`. 아이보리·크림·종이색 변형 금지
2. **딥그린 존치 구역(악센트)**: 상단 네비/헤더, CTA 버튼, 섹션 라벨(LEARN·PLAY 등), 푸터. 카드 하단 그라데이션 오버레이도 유지
3. 본문 텍스트: 다크그린 또는 차콜 — 종이 위 가독 대비 유지 (WCAG AA 수준)
4. 섹션 리듬: 화이트 ↔ 아주 옅은 그린 틴트(`#EFF5F1`급) 교차로 단조로움 방지. 전면 딥그린 섹션은 푸터 하나만 남긴다
5. 수채화 이미지는 화이트 바탕에 그대로 얹는다 — 카드 흰 배경과 바탕이 경계 없이 이어지게

## 금지
카피·문구 변경 금지 / 레이아웃 구조 변경 금지(색·배경만 — 카드 크기는 별도 지시서_홈_카드축소.md) / 학습 페이지(/learning)·pricing은 손대지 않는다 / 로고·수채화 이미지 수정 금지
