# 코다리 지시서 — 홈 디자인 통합 개편 · 최종판 (2026-08-05)

> ⚠️ 이 문서가 디자인 지시의 유일 정본이다. 기존 3장(카드축소·화이트전환·중앙집중)은 전부 폐기 — 열지도 마라.
> 대표님 불만 원문 종합: "다 늘여 꽉 채워 옛날 사이트 같다 / 카드만 작아지고 나머지 그대로 / 너무 작아 눌린 것 같다 / 그림이 잘린다 / 색이 강하다"

## 완성 상(像) — 한 문장
**순백 종이 위, 가운데 콘텐츠 기둥 하나. 크지도 작지도 않은 카드에 그림이 잘리지 않게. 양옆은 넉넉한 흰 여백.**

## 사양 (전부 랜딩 = src/App.tsx + src/index.css 한정)
1. **배경**: 페이지 전체 순백 `#FFFFFF`. 연민트·회색 배경 전면 제거. 섹션 구분이 필요하면 아주 옅은 그린 틴트(`#F3F8F5`) 한 단계만 교차 사용
2. **콘텐츠 기둥**: 모든 섹션 래퍼 `mx-auto max-w-6xl px-6`. 문단 텍스트는 `max-w-2xl`. 풀블리드 허용은 푸터 배경 하나뿐
3. **히어로**: 중앙 세로 스택 — INKWORD → 헤드라인("외우지 말고, 보세요.") → 서브("눈앞에서 그려지는 단어장.") 를 `text-center mx-auto max-w-3xl`로 한 덩어리. 좌우 분리 배치 폐지. 위아래 여백 `pt-24 pb-16`
4. **기능 카드 4장 (핵심 불만 구역)**:
   - 그리드: `mx-auto max-w-5xl grid-cols-2 gap-6` — 지금(3xl)은 너무 눌렸다, 한 단계 키운다
   - 그림틀: `aspect-[3/2]` — 16:7.5는 폐기(너무 납작해서 그림이 잘림)
   - 이미지: `object-cover object-center` 유지하되, **4장 모두 주요 피사체가 잘리지 않는지 눈으로 확인** — 잘리면 그 카드만 `object-top` 등 위치 조정
   - 카드 하단 제목 오버레이·번호·태그 현행 유지
5. **수직 리듬**: 섹션 `py-20 sm:py-24` 통일. 섹션 사이 여백이 균일해야 한다
6. 모바일 390px: 카드 2열 유지하되 gap-3, 히어로 폰트 축소 — 가로 스크롤 절대 금지
