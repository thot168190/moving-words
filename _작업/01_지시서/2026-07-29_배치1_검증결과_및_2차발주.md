## ★ 오류 패턴 하나를 짚는다 — 관사

**관사 누락 3건이 전부 「8단어 이내」를 맞추려다 생겼다.**

```
Red balloon floated into the sky.        ← a 를 빼서 7단어
Door shut with a loud bang.              ← The 를 빼서 6단어
The bomb exploded in desert.             ← the 를 빼서 5단어
```

**단어 수를 맞추려고 관사를 빼지 마라. 틀린 영어가 된다.**
8단어를 넘으면 **문장을 더 짧게 다시 써라.**

```
✗ Red balloon floated into the sky.       (관사를 뺐다)
✓ A red balloon flew up.                  (짧게 다시 썼다)
```

## 2차 발주 — 번호 101~1200 (1,100개)

### 진행
```
101~300   → data/_batch2/batch_02.json ~ batch_03.json   → 제출하고 멈춤 ★
승인 후
301~700   → batch_04 ~ batch_07                          → 제출하고 멈춤 ★
승인 후
701~1200  → batch_08 ~ batch_12
```

**200개씩 끊어서 검증받는다.** 1,100개를 한 번에 하지 마라.

### 배치 1에서 확인된 규칙에 추가할 것

1. **관사(a/an/the)를 반드시 확인하라.** 8단어 제한보다 문법이 우선이다
2. **한국어 맞춤법을 확인하라.** `짖다/짓다`, `되다/돼다`, `-데/-대`
3. **직역 금지.** `녹색 콩`, `여행 대리인`, `해만` 같은 사전에 없는 조어를 만들지 마라
4. **차별적·구시대적 표현 금지.** `맹인` → `시각장애`, `벙어리` → `말을 못 하는`
   우리 제품은 중학생이 보는 교육 콘텐츠다
5. 다의어 로그는 배치 1처럼 계속 써라. **배치당 20~40개 나오는 게 정상이다**
