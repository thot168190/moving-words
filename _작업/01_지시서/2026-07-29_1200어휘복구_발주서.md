## 1. 무엇이 잘못됐나 (읽고 시작해라)

원본 1200개 중:

```
한국어 뜻   472개가 문자열 "nan"        → 39.3% 누락
품사        1200개 전량이 가짜
            명사299 / 동사308 / 형용사297 / 부사296  ← 정확히 4등분
            accept="명사", accident="동사", achieve="형용사"
            → 누군가 순서대로 돌려가며 찍었다. 데이터가 아니다.
```

**너의 임무는 이 두 칸을 사실로 채우는 것이다.** 그 외 칸은 건드리지 마라.

## 2. 산출물

**파일**: `data/1200_어휘복구_v1.json`

**스키마** — 원본 레코드를 그대로 복사하고 아래 4개 필드를 **추가/덮어쓰기**:

```json
{
  "번호": 1,
  "영어 표제어": "accept",
  "한국어 뜻": "받아들이다, 수락하다",
  "품사": "v.",
  "예문": "I accept your apology.",
  "예문 해석": "네 사과를 받아들일게.",
  "공식 분류": "중·고 공통 권장(**)",
  "시각화 점수": 66,
  "난이도": "중등 핵심",
  "복습 대상 여부": "X",
  "복습 챕터": "N/A",
  "복습 이유": "N/A",
  "유지/교체/보조어 판정": "유지"
}
```

앞의 4개(한국어 뜻·품사·예문·예문 해석)만 네가 만든다. 나머지는 원본 그대로 복사.

최상위 구조는 원본과 동일하게 `{ "summary": ..., "words": [...], "exposures": ... }` 유지.
`summary` 에 `"복구일": "2026-07-29"`, `"복구도구": "kodari"` 추가.

## 3. 각 칸 작성 규칙

### 「한국어 뜻」
- **중학생이 이해하는 말**로. 1~3개, 쉼표로 구분
- 가장 흔한 뜻을 **맨 앞**에
- 한자어 남발 금지. `수용하다` 보다 `받아들이다`
- 동사는 `-다` 로 끝낸다. 명사는 명사형 그대로
- **원본에 뜻이 이미 있으면 그대로 두되**, 어색하거나 틀렸으면 고쳐라 (고친 건 §5에 기록)

### 「품사」 — 아래 표기만 허용
```
n.  v.  adj.  adv.  prep.  conj.  pron.  num.  int.  det.
```
- 복수 품사는 슬래시: `travel` → `v./n.`
- **주된 품사를 앞에.** 중등 교과 기준 사용 빈도로 판단
- ⚠️ **분포를 억지로 맞추지 마라.** 영어 기초 어휘는 명사가 가장 많다. 4등분이 나오면 그건 또 가짜다

### 「예문」
- **8단어 이내**, 중1~중3이 읽을 수 있는 문장
- 표제어를 **반드시 포함**. 굴절형 허용 (accept → accepted)
- 고유명사·문화 특수 표현 금지
- 마침표/물음표로 끝낸다

### 「예문 해석」
- 자연스러운 한국어. 직역체 금지

## 4. 진행 방식 — 100개씩 12배치

```
배치 1  : 번호   1~100    →  data/_batch/1200_batch_01.json
배치 2  : 번호 101~200    →  data/_batch/1200_batch_02.json
...
배치 12 : 번호 1101~1200  →  data/_batch/1200_batch_12.json
마지막  : 12개 배치를 합쳐 data/1200_어휘복구_v1.json 생성
```

**배치마다 저장하는 이유**: 중간에 끊겨도 처음부터 안 해도 된다. 이미 있는 배치 파일은 건너뛰어라.

한 배치를 끝낼 때마다 한 줄만 출력:
```
[배치 03] 100개 완료 — 뜻 신규 41 / 뜻 수정 6 / 품사 전량 재작성
```

## 6. 검증 — 끝나면 반드시 실행

`scripts/verify_1200.mjs` 를 아래 내용으로 만들고 `node scripts/verify_1200.mjs` 실행.

```javascript
import fs from 'fs';
const j = JSON.parse(fs.readFileSync('data/1200_어휘복구_v1.json','utf8'));
const w = j.words;
const POS = ['n.','v.','adj.','adv.','prep.','conj.','pron.','num.','int.','det.'];
let fail = 0;
const bad = (m)=>{ console.log('❌ '+m); fail++; };

if (w.length !== 1200) bad(`개수 ${w.length} (기대 1200)`);
const nums = new Set(w.map(x=>x['번호']));
for (let i=1;i<=1200;i++) if(!nums.has(i)) { bad(`번호 ${i} 누락`); break; }

const nanCnt = w.filter(x=>!x['한국어 뜻'] || /^\s*(nan|null|undefined)?\s*$/i.test(String(x['한국어 뜻']))).length;
if (nanCnt) bad(`뜻 누락/nan ${nanCnt}개`); else console.log('✅ 뜻 누락 0');

const badPos = w.filter(x=>!String(x['품사']).split('/').every(p=>POS.includes(p.trim())));
if (badPos.length) bad(`품사 표기 오류 ${badPos.length}개 예: ${badPos.slice(0,5).map(x=>x['영어 표제어']+'='+x['품사']).join(', ')}`);
else console.log('✅ 품사 표기 정상');

const cnt = {};
w.forEach(x=>{ const p=String(x['품사']).split('/')[0].trim(); cnt[p]=(cnt[p]||0)+1; });
console.log('품사 분포:', cnt);
const four = ['n.','v.','adj.','adv.'].map(p=>(cnt[p]||0)/1200);
if (four.every(r=>r>0.22 && r<0.28)) bad('품사가 또 4등분이다. 가짜다. 다시 해라');
else console.log('✅ 분포 자연스러움');

const ANS = {accept:'v.',accident:'n.',achieve:'v.',advise:'v.',ambulance:'n.',
 angry:'adj.',beautiful:'adj.',blow:'v.',carefully:'adv.',danger:'n.',
 dangerous:'adj.',decide:'v.',easily:'adv.',forget:'v.',happy:'adj.',
 honest:'adj.',quickly:'adv.',sudden:'adj.',suddenly:'adv.',hospital:'n.'};
let miss=0;
for (const [k,v] of Object.entries(ANS)) {
  const r = w.find(x=>x['영어 표제어']===k);
  if (!r) continue;
  if (String(r['품사']).split('/')[0].trim() !== v) { console.log(`  ✗ ${k}: ${r['품사']} (정답 ${v})`); miss++; }
}
if (miss) bad(`스팟체크 ${miss}/20 오답`); else console.log('✅ 스팟체크 20/20');

const noWord = w.filter(x=>{
  const s=String(x['예문']||'').toLowerCase();
  const h=String(x['영어 표제어']).toLowerCase();
  return !s.includes(h.slice(0, Math.max(3, h.length-2)));
});
if (noWord.length) bad(`예문에 표제어 없음 ${noWord.length}개 예: ${noWord.slice(0,5).map(x=>x['영어 표제어']).join(', ')}`);
else console.log('✅ 예문 표제어 포함');

const long = w.filter(x=>String(x['예문']||'').split(/\s+/).length > 8);
if (long.length) console.log(`⚠️ 8단어 초과 예문 ${long.length}개 (경고)`);

console.log(fail ? `\n=== 실패 ${fail}건 ===` : '\n=== 전 항목 통과 ===');
process.exit(fail?1:0);
```

**`=== 전 항목 통과 ===` 가 뜰 때까지 고쳐라.** 통과 못 하면 그 상태 그대로 보고해라. 통과했다고 거짓말하지 마라.
