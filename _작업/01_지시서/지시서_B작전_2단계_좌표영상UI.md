# B작전 2단계 지시서 — 좌표·영상·UI (2026-08-23 로부장)

> 1단계(단어층) 성공 확인됨. 그러나 화면 성립엔 세 층이 더 필요하다: 좌표(사물 위), 영상(신세대), UI(가변 레벨).
> 실행 전부 코다리. 판단 필요 지점은 대표님 클릭으로 해결한다 — 에이전트 추측 좌표 금지.

## 임무1 — 좌표 에디터 (최우선, 이게 없으면 영원히 라벨이 허공에 뜬다)
1. 학습 페이지에 **관리자 좌표 모드** 추가 (URL 파라미터 `?edit=1`일 때만 활성):
   - 장면 화면에서 단어 라벨을 **드래그로 이동** 가능
   - [좌표 내보내기] 버튼 → 해당 장면의 단어별 좌표 JSON을 클립보드 복사
   - 일반 사용자 화면에는 어떤 흔적도 없어야 함
2. 대표님 동선: 장면 열기 → 라벨 8개 드래그(사물 위로) → 내보내기 → 코다리가 데이터에 반영
3. 완료 증빙: ?edit=1 화면 스크린샷 + 드래그→내보내기→반영 1장면 시연 diff

## 임무2 — 레벨 탭 가변화
1. LEVEL 1/2 탭이 **각 레벨의 실제 단어 수(0~10)를 그대로 수용**하도록 수정 (4+4 고정 가정 제거)
2. 레벨 배분은 명세·매칭표의 level 값만 사용 — 임의 4/4 분할 금지 (돌고래 장면 재배분 포함)
3. 한 레벨이 0개면 그 탭은 숨김

## 임무3 — 챕터1 영상 세대 교체 (파일 지정제)
1. 대상: 돌고래가 따라오는 배(현재 엉뚱한 실험판), 고래와 깊은 바다(실사 손 구판) 우선
2. **대표님이 합격본 mp4 파일을 지목**하면(파일명 전달) 코다리는 교체·포스터(끝 프레임)·톤 표준 적용만
3. 대표님 지목 전에는 영상에 손대지 않는다 — 추측 교체 금지
