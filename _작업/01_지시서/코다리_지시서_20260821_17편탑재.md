## STEP 3 · 인코딩 + 포스터 추출

```bash
for f in "$OUT"/*.mp4; do
  b=$(basename "$f" .mp4)
  ffmpeg -y -i "$f" -vf "scale=1280:-2" -c:v libx264 -crf 24 -preset slow \
    -movflags +faststart -an "$OUT/${b}_web.mp4" 2>/dev/null
  ffmpeg -y -ss 00:00:07.5 -i "$f" -vframes 1 -q:v 3 "$OUT/${b}-poster.jpg" 2>/dev/null
```

## STEP 5 · chapterData 삽입 ★사고 다발 구간

**`scenes.json`은 존재하지 않는다.** 데이터는 `public/learning/index.html` 안의 `chapterData`에 있다. 없는 파일을 찾지 마라.

`chapterData[N]`은 **배열 5개**로 되어 있고 **길이가 전부 같아야 한다.**
```
works · levelOneWords · levelTwoWords · sceneSpots · levelOneSpots
```
works만 넣고 나머지 4개를 빠뜨린 사고가 있었다. **5개를 전부 센 뒤 보고한다.**

**한국어 뜻을 지어내지 마라.** 정본 csv에 뜻 컬럼이 없다. 모르면 빈칸으로 두고 보고한다. (`dump`→"더미", `bare`→"민둥한" 창작 사고 이력)

## STEP 6 · 문법 검사 ★배포 전 의무

2026-08-12에 `else` 고아로 사이트가 백지가 된 사고가 있었다.

```bash
node -e "const fs=require('fs');
for(const p of ['public/learning/index.html','dist/learning/index.html']){
 if(!fs.existsSync(p))continue; const s=fs.readFileSync(p,'utf8');
 const m=[...s.matchAll(/<script(?![^>]*src)[^>]*>([\s\S]*?)<\/script>/g)];
 let bad=0; m.forEach(x=>{try{new Function(x[1])}catch(e){bad++;console.log('FAIL',p,e.message)}});
 console.log(p, bad?'문법 FAIL':'문법 PASS');}"
```
**FAIL이면 절대 배포하지 말고 멈춰서 보고.**

참조 실존 검사도 함께.
```bash
node -e "const fs=require('fs');const s=fs.readFileSync('public/learning/index.html','utf8');
const r=[...new Set([...s.matchAll(/ch[0-9]+\/[^\"']+\.(mp4|jpg)/g)].map(m=>m[0]))];
```
