# 코덱스 협업 지시서 — 장면 프롬프트 작문 (v1, 2026-07-30)

> 발신: 로부장 | 수신: 코덱스
> 전임자(코다리)는 프롬프트 생성 스크립트를 짜서 돌리다 3회 반려 후 이 공정에서 퇴출됐다.
> 이 일은 코딩이 아니라 **작문**이다. 그 전제를 받아들일 수 없으면 시작하지 마라.

## 0. 역할 분담
- **코덱스(너)**: 장면마다 프롬프트를 직접 작문
- **로부장**: 기계 검문(qc_scene.py) + 정독 검수 — 네 보고는 신뢰하지 않고 전수 재검한다
- **대표님**: Flow 생성 + 그림 최종 판정

## 1. 절대 규칙
1. ⛔ **프롬프트 생성기·템플릿 스크립트 작성 금지.** "N개를 코드로 찍어내자"는 생각이 드는 순간이 실패의 시작이다. 장면 하나에 문장 하나하나를 네가 쓴다.
2. 단어의 **철자가 아니라 뜻이 그림이 된다.** afford라는 단어가 있으면 'afford'라는 글자가 아니라 "동전을 세어보고 빵을 가리키는 손" 같은 장면을 그린다. 추상어는 사물의 관계·크기·위치로 뜻을 보여준다.
3. 골격 v3(장면작업대.html 내장)의 HEAD/드로잉/채색/움직임/STYLE/NEVER 문장은 한 글자도 바꾸지 않는다. 네가 쓰는 건 슬롯 3개다:
   - **A 피사체** 3~5개 — 프레임에 잘리는 요소 1 + 스케일 대비 1 필수
   - **B 색** 3~4개 구체 명명 — 여름 채도, 원색 금지
   - **C 마지막 2.5초** — 빛의 사건 또는 살아있는 동작 1~2 (와 요소)
4. 단어는 `all1200.txt`에서만. 단, `used_words.txt`의 단어는 이미 완성된 12장면이 사용했으므로 **제외**. 잔여 단어 각각 정확히 1개 장면에 배정.
5. 장면 단어는 `1200_분류.json`의 해당 갈래에서, 레벨 비율(레벨2 ≥ 1/3, `1200_레벨태그_v3.csv`) 맞출 때만 타 갈래 손님 최대 2개.
6. 장면당 단어 5~10개(가변 — 그림 진실이 결정), 프롬프트 100% 영어, 장면 번호를 프롬프트 본문에 쓰지 마라.
7. 품질 기준 = 장면작업대.html의 범선 견본. 네 문장을 화가에게 줬을 때 그림이 그려지는가를 매 장면 자문하라.

## 2. 파일럿 프로토콜 (필수 — 건너뛰면 전량 반려)
1. `1200_분류.json`에서 미완 갈래 하나를 골라 **그 갈래만** 작문 (6~8장면 내외)
2. `python3 qc_scene.py scenes/` 통과 확인
3. **거기서 멈추고 제출.** 로부장 정독 합격 후에만 나머지 갈래 진행 승인이 나온다.

## 3. 산출 형식
`scenes/scene_NNN_갈래명_partN.json`
```json
{"name":"장면 이름(한글)","갈래":"분류.json의 실제 갈래명","words":["..."],"prompt":"골격 v3 완성 전문"}
```

## 4. 보고 양식
qc_scene.py 출력 원문 + 장면 수 + 사용 단어 수. 수사여구·이모지·충성 구호 금지. 팩트만.
