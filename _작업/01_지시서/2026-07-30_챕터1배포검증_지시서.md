## 명령 — 이 한 줄을 그대로 실행하고 출력 전문을 붙여넣는다

```bash
cd "$HOME/workspace/움직이는그림사전" && \
L=/tmp/live_ch1.html && curl -s "https://inkword.site/learning/index.html?cb=$RANDOM" -o "$L" ; \
V=_작업/01_지시서/verify_ch1.mjs ; \
echo "########## 1) 로컬 소스 ##########" ; node "$V" public/learning/index.html ; \
echo "########## 2) 빌드 산출물 dist ##########" ; node "$V" dist/learning/index.html ; \
echo "########## 3) 라이브 서버 ##########" ; node "$V" "$L" ; \
echo "########## 4) 09 실물 파일 ##########" ; ls -la dist/learning/챕터1_완성동영상/scene-ch1-09* ; \
echo "########## 5) gh-pages 브랜치 ##########" ; git ls-tree gh-pages --name-only learning/ | head -20 ; \
echo "########## 6) 라이브 09 응답 ##########" ; \
curl -s -o /dev/null -w "mp4    %{http_code}  %{size_download} bytes\n" "https://inkword.site/learning/챕터1_완성동영상/scene-ch1-09.mp4" ; \
curl -s -o /dev/null -w "poster %{http_code}  %{size_download} bytes\n" "https://inkword.site/learning/챕터1_완성동영상/scene-ch1-09-poster.jpg"
```

⚠️ **`&&` 대신 `;`를 쓴 이유**: 검증기는 실패하면 종료코드 1을 낸다. `&&`로 묶으면
1)에서 실패하는 순간 2)~6)이 안 돌아서 **어디까지 반영됐는지 알 수 없다.**
`;`로 묶어야 6개 구간이 전부 돌고, 그 차이가 원인을 알려준다.
