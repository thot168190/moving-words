## 0. 왜 이 문서가 필요한가

대표님이 크롬 확장 벌크를 유료로 붙여 **영상이 대량으로 먼저 나오는 구조**가 됐다.
그러면 순서가 이렇게 된다.

```
영상 여러 편 완성  →  영상을 보고 단어를 고른다  →  좌표를 찍는다  →  사이트에 넣는다  →  배포
```

**이 순서에는 함정이 두 개 있고, 둘 다 이미 사고가 났다.**

| 사고 | 무슨 일이 있었나 |
|---|---|
| **단어가 그림에 없다** | 「자전거와 수레」 그림에 `motor`·`vehicle`이 붙었다. 그림에 모터가 없다 |
| **좌표를 그림 안 보고 찍었다** | 47편이 네 귀퉁이 고정값으로 나갔다. 단어가 엉뚱한 자리를 가리켰다 |

**이 문서의 목적은 그 둘을 구조적으로 막는 것이다.**

## 1. 파일명 규칙 — 어기면 배포에서 누락된다

```
public/learning/ch{N}/ch{N}_{MM}.mp4
public/learning/ch{N}/ch{N}_{MM}-poster.jpg
```

- `N` = **사이트 챕터 번호** (폴더 ch1~ch4는 옛 폴더다. 헷갈리지 마라)
- `MM` = 두 자리 (`01` `02` … `12`)
- **공백·한글·특수문자 금지.** 2026-08-17에 파일명의 `…`(U+2026) 때문에 gh-pages가 3편을 안 올렸다
- 포스터는 **반드시 있어야 한다.** 좌표를 찍으려면 그림을 봐야 한다

```bash
# 포스터가 없으면 영상 첫 프레임에서 뽑는다
ffmpeg -i ch8/ch8_05.mp4 -vframes 1 -q:v 2 ch8/ch8_05-poster.jpg
```

## 2. 매칭 5단계

### STEP 1 — 그 챕터에 남은 단어를 본다

```bash
python3 _작업/scene_tool.py remain 8
```

갈래별로 아직 안 쓴 단어가 나온다. **여기 없는 단어는 쓰지 마라.**
어느 챕터에도 안 들어간 갈래를 보려면:

```bash
python3 _작업/scene_tool.py free
```

### STEP 2 — 포스터를 열고 보이는 것만 고른다

**이 단계가 이 문서의 전부다.**

포스터 이미지를 **직접 열어서 본다.** 그리고 STEP 1 목록에서
**그림에 실제로 보이는 것**만 고른다. 8~12개.

| 규칙 | |
|---|---|
| 그림에 없으면 안 넣는다 | 억지로 채우지 마라. 8개만 되면 8개다 |
| 추상어는 관련 사물 근처에 | `climate`는 하늘, `duty`는 근무 자리 |
| 눈에 안 보이고 관련 사물도 없으면 빼라 | 그 단어는 다른 편에 간다 |

**포스터를 못 열면 여기서 멈추고 보고하라.** 추측으로 고르지 마라.

### STEP 3 — 뜻을 붙인다

**대표님 지시 — 뜻이 영어 단어보다 어려우면 뜻칸이 아니라 벽이다.**

| 나쁨 | 좋음 |
|---|---|
| marvel = 경이 | marvel = **놀라운 것** |
| comfort = 위안 | comfort = **편안함** |
| panic = 공황 | panic = **겁에 질림** |
| post = 초소 | post = **지키는 자리** |
| motor = 모터 | motor = **모터(전동기)** |

- 중등 수준 · 한자어 피하기 · 음차(영어를 한글로만 옮긴 것) 피하기
- **그림이 보여주는 품사**로 잡는다 — `patient`가 「환자」인지 「참을성 있는」인지는 그림이 정한다
- **같은 편 안에서 뜻이 겹치면 안 된다.** `joy`와 `delight`를 둘 다 「기쁨」으로 넣은 사고가 있었다

### STEP 4 — 좌표를 찍는다

포스터를 보며 각 단어가 가리키는 것의 위치를 **가로%(왼쪽 0→오른쪽 100), 세로%(위 0→아래 100)** 로 적는다.

| 규칙 | 이유 |
|---|---|
| x, y 는 **8~92** | 가장자리에 붙으면 글자가 잘린다 |
| 같은 레벨 안 거리 **18 이상** | 글자가 포갠다 |
| **좌우대칭·격자 금지** | `[[20,20],[80,20],[20,80],[80,80]]` 같은 모양이 나오면 그림을 안 본 것이다 |
| 주인공을 가리지 않는다 | 그림의 중심은 비운다 |
| 긴 단어는 중앙 쪽으로 | `temperature`는 가로로 길게 뻗는다 |

**최상위 기준은 대표님 지시다.**

> **"정상적으로 보이느냐가 기준이다. 규칙을 다 지켜도 화면에서 어색하면 실패다."**

다 찍은 뒤 그림을 다시 열어 자문하라 — 주인공 가림 / 글자 부딪힘 / 한쪽 쏠림 / 가장자리 잘림 / 빈 데 혼자 뜸.

### STEP 5 — JSON으로 적는다

`_작업/새편/ch8_05.json`

```json
{
  "chapter": 8,
  "n": "05",
  "title": "항구의 새벽",
  "sub": "배가 들어오는 시간",
  "video": "ch8/ch8_05.mp4",
  "img":   "ch8/ch8_05-poster.jpg",
  "levelOne": [ ["dock","부두",[35,62]], ["cargo","화물",[62,58]],
                ["crew","선원",[48,74]], ["harbor","항구",[22,40]] ],
  "levelTwo": [ ["anchor","닻",[70,55]], ["rope","밧줄",[58,80]],
                ["deck","갑판",[44,52]], ["tide","조수",[80,72]] ]
}
```

- **좌표를 단어에 붙여 쓴다.** 배열을 따로 두면 순서가 어긋나 사고가 난다
- `levelOne`은 **4개** — 퀴즈가 이 4개를 쓴다 (코드가 `slice(0,4)`)
- `levelTwo`는 나머지

## 3. 검사하고 넣는다

```bash
# 1) 검사 — 반드시 통과시킬 것
python3 _작업/scene_tool.py check _작업/새편/ch8_05.json

# 2) 주입 — 5배열을 스크립트가 맞춰준다. 손으로 넣지 마라
python3 _작업/scene_tool.py add _작업/새편/ch8_05.json

# 3) 전체 무결성
python3 _작업/scene_tool.py verify
python3 _작업/verify_spots.py public/learning/index.html
```

`check`가 잡는 것 — 정본 1200 밖 단어 · 다른 편에서 쓴 단어 · 뜻 중복 · 뜻 빈칸 · 좌표 범위 · 좌표 겹침 · **좌우대칭/격자** · 영상·포스터 파일 존재 · 파일명 특수문자 · 편 중복

**★ 하나라도 뜨면 넣지 마라.** 고치고 다시 돌려라.

### 배포

```bash
diff -q public/learning/index.html dist/learning/index.html && echo "동일 OK"
npx gh-pages -d dist

git fetch origin gh-pages
git show origin/gh-pages:learning/index.html > /tmp/live.html
python3 _작업/verify_spots.py /tmp/live.html
```

- `npm run build` **금지** — 카드사 심사 중
- Netlify **금지** · `--no-history` **금지**

## 6. 기존 편에 단어를 더 넣을 때

새 영상 없이 **294개**를 소화할 수 있는 자리다. **이게 가장 싸다.**

절차는 위와 같되 `add` 대신 기존 편을 고친다. 넣는 자리가 **세 곳**이고 하나라도 빠지면 그 편이 안 열린다.

```
works[k].words     ← ["영어","뜻"] 추가
levelTwoWords[k]   ← 같은 쌍 추가
sceneSpots[k]      ← 그 단어의 좌표를 같은 순서로 추가
```

`levelOne`은 4개를 넘기지 마라. 추가분은 전부 `levelTwo`로 간다.
**편당 5.4개인 ch3가 여유가 가장 크다.**

## 7. 절대 하지 말 것

- **포스터를 안 보고 단어를 고르거나 좌표를 찍기** — 47편이 그렇게 망가졌다
- **그림에 없는 단어를 억지로 넣기** — 빼고 보고하는 게 맞다
- 5배열을 손으로 맞추기 — `scene_tool.py add` 를 써라
- `check` 를 건너뛰고 `add` 하기
- 파일명에 공백·한글·특수문자
- **뜻을 영어보다 어렵게 쓰기**
- `npm run build` · Netlify · `--no-history`
- **판정을 스스로 하기** — 그림 합격·불합격, 뜻 최종 확정, 챕터 구조는 **대표님 영역이다**

## 8. 도구 요약

| 도구 | 언제 |
|---|---|
| `scene_tool.py remain <ch>` | 그 챕터에 남은 단어 보기 |
| `scene_tool.py free` | 갈 곳 없는 갈래 보기 |
| `scene_tool.py check <json>` | **넣기 전 필수** |
| `scene_tool.py add <json>` | 주입 (5배열 자동) |
| `scene_tool.py verify` | 전체 무결성 |
| `verify_spots.py <html>` | 좌표 전수 검사 (기본값·대칭·겹침) |
| `verify_prompt.py <파일>` | **프롬프트를 Flow에 넣기 전** 정본 검증 |

프롬프트를 새로 쓸 때는 정본 두 파일에서 슬롯만 갈아끼운다. **창작 금지.**

```

CALM (쉼)  _작업/성공문법_정본_line-reveal_20260809.md §1   망원경
```
