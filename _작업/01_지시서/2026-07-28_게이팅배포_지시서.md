## 2. 할 일

### 작업 1 — 빌드 및 배포

```bash
npm run build && cp -R dist/* dist-final/
```

빌드가 성공하면 **GitHub Pages 로 배포**한다. (지금 `inkword.site` 는 `gh-pages` 브랜치가 서빙 중이다. Netlify 아님)

### 작업 2 — 구버전 번들 정리

빌드하면 `dist-final/assets/` 에 새 JS 번들이 생기고 옛 번들이 남는다.

```bash
grep -o 'assets/index-[A-Za-z0-9_-]*\.js' dist-final/index.html
ls dist-final/assets/
```

`index.html` 이 참조하지 **않는** JS 파일은 `_to_delete/` 로 옮겨라. **삭제하지 말고 이동만 하라.**

### 작업 3 — Firestore 보안 규칙 배포 (되면)

```bash
firebase deploy --only firestore:rules
```

**Firebase CLI 로그인이 안 되어 있으면 `SKIP: firebase 미로그인` 이라 표시하고 넘어가라.** 대표님이 콘솔에서 직접 붙여넣을 것이다. 로그인을 새로 시도하지 마라.

## 3. 자가검증 (필수 — 출력 원문 없으면 전량 반려)

배포 완료 후 아래를 **그대로 실행**하고 출력 전체를 붙여라.

```bash
echo "=== [A] 게이팅 ==="
curl -sL https://inkword.site/learning/index.html | grep -c "FREE_SCENES=3"
curl -sL https://inkword.site/learning/index.html | grep -c "needsPurchase"
curl -sL https://inkword.site/learning/index.html | grep -c "inkword:need-purchase"

echo "=== [B] 사업자 주소 ==="
curl -sL https://inkword.site | grep -c "105동 603호"
curl -sL https://inkword.site | grep -c "010-2058-9900"

echo "=== [C] 프리렌더 유지 ==="
curl -sL https://inkword.site | wc -c
curl -sL https://inkword.site | grep -c "외우지 마세요"

echo "=== [D] 번들 정합 ==="
grep -o 'assets/index-[A-Za-z0-9_-]*\.\(js\|css\)' dist-final/index.html
ls -la dist-final/assets/

echo "=== [E] 학습장 캐시 버전 ==="
curl -sL https://inkword.site | grep -o "learning/index.html?v=[0-9a-zA-Z-]*" | head -1
```

### 합격 기준

| 항목 | 기대값 |
|---|---|
| `[A]` `FREE_SCENES=3` | **1** |
| `[A]` `needsPurchase` | **2 이상** |
| `[A]` `inkword:need-purchase` | **1 이상** |
| `[B]` `105동 603호` | **1 이상** |
| `[B]` `010-2058-9900` | **1 이상** |
| `[C]` `wc -c` | **10000 이상** |
| `[C]` `외우지 마세요` | **1 이상** |
| `[D]` `index.html` 이 참조하는 js·css | **전부 `dist-final/assets/` 에 실재** |
| `[D]` `dist-final/assets/` 안의 js 파일 | **1개만** (구버전은 `_to_delete/` 로) |

**하나라도 어긋나면 미완료다.** 다시 확인하라.
