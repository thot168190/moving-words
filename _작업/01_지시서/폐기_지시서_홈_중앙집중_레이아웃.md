# 코다리 지시서 — 홈 중앙 집중 레이아웃 (2026-08-05 대표님 확정)

> 지침 원문: "가운데로 몰아서 집중하게. 지금은 다 늘여 꽉 채워서 옛날 사이트 같다."
> 원칙: **콘텐츠는 가운데 기둥, 양옆은 숨 쉬는 여백.** 클래스 조정만 — 구조·색·카피·기능 변경 금지.

## 작업 (src/App.tsx 랜딩 한정)
1. **전역 폭 기둥**: 모든 섹션의 콘텐츠 래퍼에 `mx-auto max-w-6xl px-5 sm:px-8` 적용
   (이미 좁은 래퍼가 있으면 유지. w-full·max-w-none·화면폭 그리드는 전부 이 기둥 안으로)
2. **글 컬럼은 더 좁게**: 문단·설명 텍스트 블록은 `max-w-3xl`(제목은 max-w-4xl) — 긴 줄이 늘어지지 않게
3. **수직 리듬**: 섹션 세로 패딩을 `py-20 sm:py-28`로 통일 — 섹션 사이가 붙어 보이지 않게
4. **히어로 (최우선)**: 좌우로 찢긴 배치 폐지 — 중앙 정렬 세로 스택 한 덩어리로.
   순서: INKWORD 아이브로 → 헤드라인("외우지 말고, 보세요.") → 바로 아래 서브("눈앞에서 그려지는 단어장.") → 카드 그리드.
   전부 text-center, max-w-3xl mx-auto, 상단 여백 py-16 이상
5. 기능 카드 그리드는 로부장이 적용한 `mx-auto max-w-4xl` 유지 — 건드리지 않는다
6. 풀블리드(화면 끝까지) 허용 구역은 딱 둘: 최상단 히어로 배경, 푸터 배경. 콘텐츠는 그 안에서도 기둥 정렬

7. **페이지 배경 = 순백 #FFFFFF** (대표님 기확정 — 현재 연민트 배경 제거). 옅은 그린 틴트는 섹션 교차용으로만

## 금지
색·폰트·카피·컴포넌트 구조·기능 변경 금지 (단, 7번 배경 순백은 확정 지침이므로 예외) / 새 섹션·효과 추가 금지 / learning·pricing 페이지 접촉 금지 / "알아서 개선" 금지 — 위 6개 항목만

## 완료 판정
1. `npm run build` 성공
2. 커밋(위 변경 파일만 add) → push → npm run deploy → 커밋해시+로그
3. 스크린샷 3장: **1920px 와이드**(양옆 여백 보여야 함) / 1280px / **390px**
4. 변경한 className 목록을 diff 원문으로 첨부 ("완료했습니다" 한 줄 = 미완료)
