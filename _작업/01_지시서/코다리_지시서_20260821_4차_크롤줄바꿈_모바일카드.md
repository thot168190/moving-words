## 0. 배경 — 3차 배포 후 대표님 피드백 2건

### (A) 크롤 글자가 어절 중간에서 끊긴다

3차에서 `pre-wrap` + `6vw`로 키웠더니 **"단어장은 벽입니 / 다."** 처럼 어절 중간이 끊겼다.
잘림이 아니라 **줄바꿈 위치 문제**다. 원인 2개:

| 원인 | 설명 |
|---|---|
| `word-break` 기본값 | 한글(CJK)은 기본적으로 **어느 글자에서든** 줄바꿈된다. 영어처럼 단어 단위로 끊기지 않는다. |
| 폰트가 커서 21자 줄이 안 들어감 | `6vw`(390px에서 23.4px)로는 최장 줄이 화면을 넘어 강제로 접혔다. |

### (B) 폰에서 학습 카드 4개가 안 움직인다

**이번 배포와 무관하다. 원래 CSS가 터치 기기에서 일부러 꺼두고 있었다.**

```css
@media (hover: none),(prefers-reduced-motion: reduce){
  .group:hover .feature-card-image,
  .group:hover .feature-card-effect,
  .group:hover .feature-demo * { animation:none!important }
  .feature-card-effect,.feature-demo,.feature-fast-video { display:none }
}
```

카드 애니메이션 22개가 전부 `.group:hover`에만 걸려 있다.
폰에는 hover가 없고, 위 블록의 `(hover: none)`이 데모 레이어를 **`display:none`으로 숨긴다.**
대표님이 "원래 움직였는데"라고 하신 건 **데스크톱에서 마우스 올렸을 때의 기억**이다.

### 패치 (A) — 크롤 줄바꿈

```
before: style:{whiteSpace:"pre-wrap",fontFamily:"Pretendard, sans-serif",
               fontSize:"clamp(22px,6vw,64px)",paddingLeft:"10px",paddingRight:"10px"}
after : style:{whiteSpace:"pre-wrap",wordBreak:"keep-all",fontFamily:"Pretendard, sans-serif",
               fontSize:"clamp(17px,4.5vw,64px)",paddingLeft:"6px",paddingRight:"6px"}
```

- `wordBreak:"keep-all"` — 한글을 **어절 단위로만** 끊는다. "벽입니 / 다." 가 생기지 않는다.
- `4.5vw` — 최장 줄(21자)이 한 줄에 들어가는 크기. 접힘 자체가 없어진다.

| 화면폭 | 폰트 | 최장줄(21자) 폭 | 가용폭 | 여유 |
|---|---|---|---|---|
| 360px | 17px(하한) | 337px | 348px | 11px |
| 390px | 17.6px | 348px | 378px | 30px |
| 430px | 19.4px | 384px | 418px | 34px |
| 768px | 34.6px | 685px | 756px | 71px |
| 1422px 이상 | 64px(상한) | 1267px | 여유 | — |

크기 이력: 2차 14px → 3차 23.4px → **4차 17.6px** (390px 기준).
3차보다 작지만 **접힘이 0**이다. 더 키우면 반드시 다시 접힌다 — 21자를 한 줄에 넣는 물리적 한계다.

### 패치 (B) — 모바일 카드 애니메이션

```
(1) 차단 블록에서 (hover: none)만 제거 — 접근성 설정은 계속 존중
    before: @media (hover: none),(prefers-reduced-motion: reduce){...}
    after : @media (prefers-reduced-motion: reduce){...}

(2) 파일 끝에 터치 기기용 자동재생 블록 추가
    @media (hover: none) and (prefers-reduced-motion: no-preference){
      .group .feature-fast-video{opacity:1}
      .group .demo-word-sail{animation:demo-pop 3.2s .25s ease infinite}
      ... 총 20개 규칙 (.group:hover → .group)
    }
```

**★ 재선언에서 일부러 뺀 규칙 2개 (다시 넣지 마라)**

| 뺀 규칙 | 왜 |
|---|---|
| `.group:hover .feature-card-image,…{animation:none!important}` | 차단 블록의 **끄는** 규칙이다. 이걸 재선언하면 켜려던 애니메이션이 도로 전부 꺼진다. |
| `.group:hover .group-hover\:text-[#27765b]{…}` | Tailwind hover 색상 유틸리티. 재선언하면 터치 기기에서 **항상** hover 색이 칠해진다. |

첫 조립 때 이 둘이 섞여 들어간 것을 검증에서 잡아 제거했다. 최종본은 **20개**다.

## 코다리가 하지 말 것

- `npm run build` — 심사 중, 해시가 바뀌면 검증 경로가 전부 깨진다
- CSS 재선언 블록에 `animation:none` 또는 `group-hover` 규칙 **다시 넣기** — 위 표의 이유대로 기능이 죽는다
- `@media (prefers-reduced-motion: reduce)` 블록 제거 — 접근성 설정을 존중해야 한다
- `rotateX(22deg)` · `perspective:900px` 건드리기 — 3차에서 확정됐다
- `learning/index.html` 건드리기 — 2차 결과물이 라이브에서 정상이다
- 크롤 섹션 자체를 제거하기 — 제거는 심사 통과 후 디자인 개편 때 대표님 판단으로 한다
