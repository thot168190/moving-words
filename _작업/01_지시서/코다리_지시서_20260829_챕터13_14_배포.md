## 4. 검증 스크립트에 대해 — 걸려도 멈추지 말 것

`python3 _작업/검증_전체.py` 를 돌리면 **"고쳐야 할 것 67건 — 배포하지 마십시오"** 가 나온다.
**이건 오늘 생긴 문제가 아니다.**

- 내용은 전부 **같은 챕터 안에 같은 단어가 두 번 나오는 것**이다
- 챕터 13·14 는 **0건**이다. 전부 기존 챕터 1~12 의 것이다
- **현재 배포돼 있는 사이트에도 이미 42건이 있다.** 이 기준은 지켜진 적이 없다
- 그림으로 보면 오류가 아니다. `wing` 은 새 둥지·잠자리·단풍 씨앗 **세 그림 다 날개가 있고**,
  `shell` 은 솔방울·도토리·달팽이 **셋 다 껍질이 있다.** 그림이 판사 원칙으로는 셋 다 맞다

→ **이 60건은 이번 배포에서 손대지 않는다.** 검증 스크립트 기준을 나중에 고친다.

## 6. 알아둘 것 — git 이 막히면

이 환경에서 `git add` 가 `index.lock` 오류로 막히는 일이 있다.
파일 삭제 권한이 없어서 git 이 lock 을 지우지 못하는 것이다.
```bash
rm -f .git/index.lock
```
로 풀고 다시 시도한다.
