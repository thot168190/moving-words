# 오퍼스 지시서 — 매칭 최종 확정 및 앱 탑재 (로부장 발행)

## 0. 대전제 — 판단 금지
- **유일 정본 = `_작업/매칭표_정본.csv`** (1,200행 · 영상번호↔장면↔갈래↔단어↔레벨 확정, 기계 검증 완료)
- 출처: scenes/*.json + 1200_레벨태그_v3.csv. **"마스터 계획"·"배정챕터(안)" 시트는 폐기본 — 열람 금지**
- 단어 추가·삭제·이동·레벨 재판정 전부 금지. "단어가 부족하다/판을 다시 짜자"는 발언 자체가 규칙 위반

## 1. 원칙 하나로 끝난다
**단어는 챕터의 소유물이 아니라 영상의 소유물이다.** 영상이 어느 챕터에 있든, 그 영상의 단어(표의 해당 행)가 함께 간다. 챕터 이름과 표가 달라 보여도 그것은 불일치가 아니다 — 챕터는 영상 묶음의 라벨일 뿐.

## 2. 작업 순서
1. 앱의 각 장면 데이터에 매칭표의 해당 영상번호 행들을 그대로 붓는다 (레벨1/레벨2 탭 분류 = 표의 레벨 열 그대로)
2. **한글 뜻 채우기**: 표에 '뜻' 열 추가 — 중학생 눈높이 핵심 뜻 1~2개. 챕터1~2 기존 뜻은 변경 금지, 빈 곳만 채운다
3. 레벨에 이의가 있으면(예: 물이 레벨2 같다) **바꾸지 말고 "이의 목록"으로 별도 보고만** — 판정은 대표님·로부장
4. 탑재 후 자가 검증: 앱 전체 단어 수 = 정확히 1,200 / 중복 0 — 카운트 원문 첨부

## 3. 보고 양식
탑재한 챕터·장면 수 + 단어 카운트 원문(1,200 확인) + 뜻 채운 개수 + 이의 목록(없으면 "없음").
"완료했습니다" 한 줄 보고는 미완료로 간주한다.
