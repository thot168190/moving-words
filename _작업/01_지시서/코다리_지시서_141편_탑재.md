
**파일명 규칙 — 어기면 배포에서 누락된다**

```
public/learning/ch{N}/ch{N}_{MM}.mp4
public/learning/ch{N}/ch{N}_{MM}-poster.jpg
```

- `MM`은 그 챕터의 **다음 번호부터** 이어간다. ch2는 지금 13편이니 `ch2_14`부터
- **공백·한글·특수문자 금지.** 2026-08-17에 `…`(U+2026) 때문에 3편이 배포에서 빠졌다
- 포스터가 없으면 첫 프레임에서 뽑는다

```bash
ffmpeg -i ch2_14.mp4 -vframes 1 -q:v 2 ch2_14-poster.jpg
```

**옮긴 뒤 원본은 지우지 마라.** 나중에 교체할 때 쓴다.

**대장을 남겨라** — `_작업/141편_대장.csv`


## STEP 3 — 한 편씩 단어를 붙인다

**절차는 `코다리_지시서_그림단어매칭.md` 그대로다.** 요약하면 —

1. `python3 _작업/scene_tool.py remain 2` — 그 챕터 남은 단어 조회
2. **포스터를 먼저 열어** 무엇이 보이는지 적는다 (단어 목록보다 먼저)
3. 그림에 **실제로 보이는 것**만 5~6개 고른다
4. 뜻은 **그림이 정한다** · 영어보다 어려운 한자어 금지
5. 레벨1 3~4개 / 레벨2 2~3개
6. 좌표를 찍는다 — 8~92 범위, 거리 18 이상, **대칭·격자 금지**
7. JSON 한 장으로 적는다

```bash
python3 _작업/scene_tool.py check _작업/새편/ch2_14.json    # 반드시 통과
python3 _작업/scene_tool.py add   _작업/새편/ch2_14.json
```

**5개도 안 되면 되는 만큼만 넣고 보고하라.** 억지로 채우지 마라.

## 8. 끝나면 어디까지 오는가

```
현재     66편 · 정본 소화 406/1200 (34%)
141편 탑재 후  207편 · 편당 5.6개면 약 790개 소화 → 1196/1200 (99%)
```

**141편이 다 들어가면 1200이 거의 끝난다.** 단어가 남는 게 아니라 **그림이 남는다.**
남는 그림은 기존 편 교체용으로 쓰거나 다음 단계에서 판단한다.
