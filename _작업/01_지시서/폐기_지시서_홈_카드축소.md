# 코덱스 지시서 — 홈 기능 카드 4종 축소 (2026-07-31)

> 증상: 기능 카드(움직이는 그림 학습·거꾸로 퀴즈·그림 카드·단어 박물관)가 과대. 모바일에서 카드 1장이 화면을 가득 채움 (대표님 반려).

## 작업
1. **모바일(≤480px): 2열 그리드** — 카드 폭 반, 이미지 비율 4:3 이하로 납작하게, 카드 제목 폰트 축소(≤1rem), 번호·태그(LEARN 등) 축소
2. 데스크톱: 카드 최대 높이 제한(뷰포트의 45% 이하), 여백 축소로 4장이 스크롤 1.5화면 안에 들어오게
3. 03 '내가 만드는 그림 카드'의 밝은 배경 — 다른 3장과 동일한 하단 어두운 그라데이션 오버레이로 통일 (세트감)
4. 카드 이미지·카피·링크는 변경 금지. 크기·배치만

## 금지
색 체계 변경 금지 (딥그린 개편은 별도 지시 예정) / 카드 추가·삭제 금지 / 카피 수정 금지

## 완료 판정
배포(커밋해시+로그) + **390px 스크린샷**(4장 카드가 두 화면 안에 다 보여야 함) + 데스크톱 스크린샷
