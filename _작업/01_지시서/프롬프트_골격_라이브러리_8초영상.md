```

  3) 대표님: Flow 발사 → 판정 5항목 (요소·색·구도·동작·격조)
```

### 슬롯 채우기 규칙

| | |
|---|---|
| **A1 주역** | 반드시 **하나**. 살아있거나 밝은 것. 어두운 것·형태 없는 것(물·안개)을 주역으로 삼지 않는다 |
| **A2** | 프레임 밖으로 잘려나가야 한다. 이게 없으면 그림이 화면 중앙 웅덩이가 된다 |
| **A4** | 거대 구름 · 광활한 수평선 · 높은 수면 — 주역을 작게 보이게 하는 장치 |
| **A 총합** | 3~5개. 6개 이상은 폭주한다 |
| **B** | 색은 **대상에 붙여서** 명명한다. 「물에 파랑」이 아니라 「headland's foot에 golden sand」 |
| **B 금지** | `burgundy` 같은 강한 색은 **실제로 그 색인 대상**(산호·꽃)에만. 바위에 붙이면 분홍 바위가 나온다 |
| **C** | 빛의 사건 1개 + 주역 동작 1개 + 살아있는 동작 1개. 셋을 넘기지 않는다 |
| **Never** | 장면별 **개수 상한**(`more than one sailboat`)을 반드시 넣는다 |

## 4. 금지어 / 필수요소 (validate_8s.py와 동기화 — **스크립트가 진실**)

### 어디에도 못 쓰는 것 (부정문 포함)

```
paper  parchment  canvas  cream ground  picture frame  border  hand  pen  watermark
```

**근거(실측)**: `paper` — 성공본 0회 / 실패 v1 5회 / 실패 v2 1회.
v2는 `"no visible ... paper edge"`라고 **부정문에** 썼는데도 크림색 종이와 액자가 나왔다.
영상 모델의 텍스트 인코더는 `no`를 안정적으로 처리하지 못한다. **단어가 있으면 소환된다.**

### 본문(Never: 앞)에 못 쓰는 것

```
sepia  ink-wash  muted grey  slate blue  slate mood  storm  fog  mist  smoke  fluffy
billowing  gloomy  somber        ← 우울 유발 (v2 실패 원인)
seen from above  bird's-eye  aerial  top-down     ← 조감도 유발 (v1 실패 원인)
vertical  horizontal  16:9  9:16                  ← 비율은 Flow UI에서
children's picture-book  uncluttered  cartoon  anime  photoreal
engraving                                          ← 판화 해칭 유발. v3에서 폐기
texture,                                           ← 텍스처 지시 남발 금지 (1회 이하)
```

### 반드시 있어야 하는 것

고정부 20항목 전체 + Never 블록에 `text` `primary crayon colors` `dead-center composition`
`camera movement` `cuts` `color outside the lines` + 장면별 `more than N ...` 개수 상한.

## 5. ⚠️ 이 골격이 못 만드는 장면 (별도 골격 필요 — 미보유)

| 못 만드는 것 | 이유 |
|---|---|
| **밤 장면** (`night` `star` `moon` `dark`) | 고정부에 `clear summer daylight`가 박혀 있다 |
| **안개 장면** (`fog` `mist`) | Never에 `fog`가 있다 |
| **무지개** (`rainbow`) | Never에 `rainbows`가 있다 |
| **폭풍 장면** (`storm`) | 본문 금지어. 우울 유발 확정 |
| **구동사 도해형 288편** | 요소가 2~3개로 더 적어야 한다 |

→ 이 단어들이 필요한 장면은 **골격을 억지로 비틀지 말고**, 대표님께 밤/기상 골격을
별도 승격 요청한다. 골격을 비트는 순간 v1·v2 실패로 돌아간다.
