## ⚠️ 먼저 — 확정 사항 충돌 1건 (대표님 결정 필요)

**§2-12 목차에서 1장은 「자리와 방향」(나침반 · 전치사·접속사 91개 → 약 15편)입니다.**
그런데 현재 사이트의 챕터1은 「세상을 발견하는 순간」 = **바다 풍경 4장면**입니다.

| | §2-12 확정 목차 | 현재 사이트 |
|---|---|---|
| 1장 | 자리와 방향 (나침반/도식형) | 세상을 발견하는 순간 (풍경/장면형) |
| 근거 | 나머지 전부의 기초 · 구동사 288편의 기초 · 아무도 안 만든 구간 | 이미 만들어 둔 바다 영상 4편이 여기 있음 |

**두 갈래입니다.**

| | 뜻 | 대가 |
|---|---|---|
| **A. 바다를 1장으로 유지** | 목차를 「1장 = 바다」로 뒤집는다 | 「첫 장부터 이건 다르다」 무기를 뒤로 미룬다 |
| **B. 바다를 다른 장으로 밀고 1장은 나침반** | 목차 유지. 바다 4편은 6장(자연과 날씨)으로 이사 | 나침반 15편을 새로 만들어야 함 |

**단이 권고: A.** 이유 하나뿐입니다 — **B는 지금 발사할 게 없습니다.**
바다 영상 4편은 이미 있고, v3 골격이 방금 검증됐고, 대표님이 「챕터1 마무리」를 원하셨습니다.
나침반은 도해형이라 **별도 골격이 아직 없습니다**(라이브러리 §5 미보유 목록).
골격 없이 15편을 시작하면 v1·v2 실패로 돌아갑니다.

→ 결정하시면 그대로 갑니다. 결정 없이는 아래 기획표를 실행하지 않습니다.
