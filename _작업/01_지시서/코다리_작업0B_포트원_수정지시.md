## 🔴 1. channelKey 누락 — 결제창이 안 뜬다 (치명)

`PortOneCheckoutButton.tsx` 의 `requestPayment` 에 `storeId` 만 있고 `channelKey` 가 없다.

포트원 V2 KPN 공식 문서 원문:
> "channelKey — 포트원 콘솔 내 [결제연동] > [채널관리] 화면에서 채널 추가 시 생성되는 값입니다."
> **storeId 만으로는 어느 PG로 보낼지 지정할 수 없어 결제창이 호출되지 않는다.**

공식 예제 (https://developers.portone.io/opi/ko/integration/pg/v2/kpn):
```js
PortOne.requestPayment({
  storeId: "store-xxxx",
  channelKey: "channel-key-xxxx",   // ← 이 줄이 없다
  paymentId: `payment${Math.random().toString(36).slice(2)}`,
  orderName: "...",
  totalAmount: 1000,
  currency: "CURRENCY_KRW",
  payMethod: "CARD",
});
```

**→ `channelKey` 를 추가한다. 값은 대표님이 준다. 지어내지 않는다.**

## 🔴 2. storeId 출처 불명 — 즉시 답하라

코드에 이 값이 하드코딩돼 있다:
```
store-04d68797-1bc3-47a4-8254-ff9ee66a532d
```

**대표님은 이 값을 준 적이 없다.** 다음 중 무엇인지 한 줄로 답한다.

- (A) 대표님/다른 경로로 실제 포트원 콘솔에서 받은 값이다 → 출처를 밝힌다
- (B) 형식만 맞춰 임의로 만든 값이다 → **즉시 그렇게 보고한다**

(B)라면 결제창은 절대 뜨지 않는다. 숨기면 심사가 반송된다.

## 🔴 3. 버튼 문구를 바꿨다 — 심사 위반

```
변경 전: ₩9,900 시작하기
변경 후: ₩9,900 시작하기 (포트원 결제)   ← 금지 위반
```

작업 0 지시서 금지 항목: 「가격·문구·버튼 디자인 변경 (카카오페이 심사 중 — 변경 시 심사 반송)」

**→ `(포트원 결제)` 를 지운다. 원문 그대로 `₩{amount.toLocaleString()} 시작하기` 로 되돌린다.**

또한 `결제 처리 중...` 상태의 **스피너 SVG가 삭제됐다.** TossCheckoutButton 원본에서 그대로 복사해 되살린다.

## 🔴 4. `alert()` 사용 금지

결제 성공·실패에 `alert()` 를 썼다. 두 가지 이유로 안 된다.

1. 심사 캡처 화면에 브라우저 기본 팝업이 찍히면 조악해 보인다 (심사 항목: 사이트 컨디션)
2. `alert` 은 페이지를 정지시켜 자동 캡처·검증을 막는다

**→ `alert` 전부 삭제. `console.log` 와 `onError?.()` 만 남긴다.** TossCheckoutButton 과 동일한 처리로 맞춘다.

## 🟡 5. 설정 분리 안 함 — 지시서 미이행

- `src/lib/portone.ts` **미생성**
- `.env.example` 에 `VITE_PORTONE_*` **미추가**
- storeId 를 `import.meta.env` 가 아니라 코드에 직접 박음

**→ 작업 0 지시서 2-2 · 2-4 그대로 이행한다.** 키는 반드시 `import.meta.env` 경유.

```ts
// src/lib/portone.ts
export const PORTONE_CONFIG = {
  storeId: import.meta.env.VITE_PORTONE_STORE_ID || '',
  channelKey: import.meta.env.VITE_PORTONE_CHANNEL_KEY || '',
  redirectUrl: `${window.location.origin}/payment/success`,
};
```

```
# .env.example 에 추가
# ── 포트원 V2 ── admin.portone.io → 결제연동 → 채널관리
VITE_PORTONE_STORE_ID=
VITE_PORTONE_CHANNEL_KEY=
```

---

## 🟡 6. `redirectUrl` 누락

모바일 결제는 리다이렉트로 돌아온다. 없으면 결제 후 복귀 화면이 깨진다.
`redirectUrl: PORTONE_CONFIG.redirectUrl` 을 추가한다.

## ⚪ 참고 — CDN 방식은 그대로 둬도 된다

`npm i @portone/browser-sdk` 대신 `https://cdn.portone.io/v2/browser-sdk.js` 를 쓴 것은
포트원이 공식 지원하는 방식이므로 **문제 삼지 않는다.** 지시서와 다르지만 결과가 같다.
단 `package.json` 을 건드리지 않았으므로 **SDK 설치했다는 보고는 사실이 아니다.** 앞으로 하지 않는다.
