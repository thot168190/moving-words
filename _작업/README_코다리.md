1. `dist-final/` 폴더를 Netlify **spiffy-beijinho-7ca220** (inkword.site 연결)에 드래그

2. 배포 후 아래를 실행하고 **출력 원문 그대로** 보고

```bash
curl -sL https://inkword.site | wc -c
curl -sL https://inkword.site | grep -c "외우지 마세요"
curl -sL https://inkword.site | grep -c "영어가 싫은 아이에게 단어장은 벽입니다"
curl -sL https://inkword.site | grep -c "무료 체험"
```

**합격 기준**

| 항목 | 기대값 |
|---|---|
| `wc -c` | **10000 이상** |
| `외우지 마세요` | **1** |
| `영어가 싫은 아이에게…` | **1** |
| `무료 체험` | **0** |

하나라도 어긋나면 배포가 안 된 것이다. 다시 확인할 것.


```bash
grep -o 'assets/index-[A-Za-z0-9_-]*\.\(js\|css\)' dist-final/index.html
ls dist-final/assets/
```

## 5. 사업 방향이 바뀌었다 — 읽고 시작할 것

2026-07-26 밤, 대표님이 방향을 바꾸셨다. 코드 작업 전에 반드시 인지할 것.

- **파는 것**: 중등 일반 영단어 → **서바이벌 구동사·전치사**
- **미끼**: 1200단어 그림을 유튜브 쇼츠로 무료 공개
- **손님**: 아이 → **어른** (여행·워홀·외국인 응대). 초중등은 레벨 1·2로 수용
- **어원**: 접두사·접미사. 새 연출 엔진 필요. 미루지 않음
- **그림 스타일**: 수채화 라인아트 **유지**. 스틱맨·단순 아이콘으로 하향 금지

## 6. 절대 규칙

1. **"완료했습니다"는 근거가 아니다.** `grep` 출력 원문과 화면 측정값만 인정한다. 요약·가공 금지
2. **로부장이 같은 검증을 독립 재실행한다.** 수치가 다르면 전량 반려
3. **모든 UI 작업은 390px 스크린샷 필수.** 데스크톱만 확인하고 완료 처리 금지
4. **확정 카피는 대표님 지시 없이 한 글자도 수정 금지** (사실 오류 정정은 예외, 단 반드시 보고)
5. **막히면 `SKIP: <이유>` 표시하고 끝까지 완주 후 보고.** 단계마다 승인 요청 금지
6. **Python 실행 금지** (로컬 3.14 세그폴트). node 또는 셸을 쓸 것
7. **폴더 구조 변경·파일 이동 금지.** 루트의 기존 지시서 4종은 그대로 둘 것
8. **결제·API 키 작업은 대표님이 직접** 한다. 코다리에게 시키지 않는다
9. **부분 완료를 완료로 쓰지 말 것.** 숨기면 전량 반려
