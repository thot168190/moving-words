# 「보는 단어장」 1200 어휘 1차 검수 보고서

**2회차: No.101 ~ 200**  
**검수일: 2026년 8월 5일**

---

## 1. 작업 개요

한국 중학생을 위한 영어 단어장 「보는 단어장」의 1,200개 핵심 어휘 중 2회차 100개(No.101~200)에 대한 1차 검수 결과입니다.

각 단어는 다음 두 조건을 **동시에** 만족해야 합니다.

1. **난이도**: 중학생에게 적합한 「중등」 수준일 것 (초등·고등 제외)
2. **그림화**: 8초 애니메이션으로 표현 가능할 것 (상·중 허용, 하 제외)

이번 회차부터는 **한글 뜻** 항목이 추가되었습니다.  
배정 챕터에 맞는 대표 뜻 하나를 2~6자 이내로 선정하였습니다.

---

## 2. 판정 기준

### 난이도

| 구분 | 설명 |
|------|------|
| **초등** | 초등학교 교육과정 800단어 수준. 중학생이 이미 아는 말 |
| **중등** | 중·고 공통 기본어휘 수준 (2022 개정 교육과정 권장 1,200어휘). **목표 수준** |
| **고등** | 수능·고교 선택 수준. 중학생에게 어려움 |

### 그림화

| 구분 | 설명 |
|------|------|
| **상** | 눈에 보이는 사물·장소·동물 (예: whale, harbor) |
| **중** | 동작·상태 — 장면을 구성하면 표현 가능 (예: drift, glow) |
| **하** | 추상 개념 — 그림만으로 뜻이 드러나지 않음 (예: attitude, method) |

### 최종 판정

- **O** = 난이도가 「중등」이고 그림화가 「상」 또는 「중」
- **X** = 그 외 전부

## 3. 종합 결과

|------|------|------|
| **O (통과)** | 90개 | 90% |
| **X (제외)** | 10개 | 10% |

### X 사유 분류

- **초등 수준**: 7개  
  (wheel, towel, fit, bean, meal, plate 등)
- **고등 수준**: 1개

- **추상어 그림 불가**: 2개
