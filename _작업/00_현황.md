## 9. 결제 서비스 시장 조사 (2026-07-26)

### 조사 목적

움직이는그림사전의 초기 고정비를 최대한 **0원에 가깝게** 유지하면서, 국내 카드·간편결제와 향후 정기결제까지 확장할 수 있는 조합을 검토한다.

### 1순위 후보 — 포트원 + 추천 PG 패키지

- **포트원 Free:** 월 순거래액 5,000만원 미만이면 이용료 무료.
- 결제 통합 API, 복수 PG 연동, 결제 조회·취소·환불 관리 제공.
- 포트원 추천 패키지 이용 시 약 22만원 상당의 **PG 가입비와 연회비 면제 가능**.
- 포트원 자체가 PG사는 아니며, 실제 결제와 정산은 계약한 PG사가 처리한다.
- 결제가 발생하면 PG 카드 수수료는 별도로 발생한다.

공식 확인:
- 포트원 요금제: https://www.portone.io/pricing
- 추천 패키지: https://help.portone.io/content/content200013

### PG 후보 비교

| 후보 | 장점 | 주의점 | 적합도 |
|---|---|---|---|
| 나이스페이 | 초기비용 절감형 플랜·프로모션, 국내 결제 지원 | 가입비 면제 프로모션 종료 가능성, 계약 직전 재확인 필요 | **초기비용 우선 시 1순위** |
| 토스페이먼츠 | 결제창 UX와 개발 편의성이 좋음 | 다른 PG보다 수수료 조건이 높을 수 있어 실제 견적 필요 | 모바일 UX 우선 |
| NHN KCP | 해외카드와 대형 서비스 운영에 강점 | 초기 서비스에는 계약·운영 조건이 과할 수 있음 | 해외 확장 시 |
| 엑심베이 | 해외 통화·해외 결제 특화 | 국내 사용자 중심 서비스에는 우선순위 낮음 | 해외 판매 시 |
| 다날 | 휴대폰 소액결제·디지털 콘텐츠에 강점 | 카드 중심 서비스라면 별도 PG가 필요할 수 있음 | 소액결제 추가 시 |

나이스페이 공식 요금 확인:
- https://start.nicepay.co.kr/homepage/price.do

### 움직이는그림사전 권장 결제 구조

```text
사용자
  → 움직이는그림사전 결제 화면
  → 포트원 V2 통합 API
  → 포트원 추천 패키지에서 선정한 PG
  → 카드·카카오페이·네이버페이·토스페이
```

### 현재 권장안

1. 토스 심사 결과가 나오기 전까지 기존 **일회성 9,900원** 정책 유지.
2. 토스 승인 시 실제 수수료·가입비·정산주기를 확인한다.
3. 동시에 포트원 추천 패키지에서 나이스페이 조건을 받아 비교한다.
4. `가입비 0원 + 연회비 0원 + 정기결제 지원 + 실제 카드 수수료` 네 항목을 같은 기준으로 비교한 뒤 최종 PG를 확정한다.
5. PG 확정 전 포트원 V2 결제 게이팅 구조를 먼저 설계해 PG 교체 비용을 줄인다.

### 비용 주의사항

- **0원 시작은 고정 이용료 기준**이며 카드 결제 수수료까지 0원이라는 뜻은 아니다.
- PG 수수료, 부가세, 보증보험, 정산주기와 정산한도는 사업 유형과 심사 결과에 따라 달라질 수 있다.
- 계약 화면에 표시된 최종 조건을 캡처하여 `_작업/03_증거/`에 보관한 뒤 결정한다.
- 현재 코드에는 결제 여부를 확인하는 게이팅 로직이 없으므로, PG 선정과 별개로 결제 완료 검증 및 이용권 권한 저장을 반드시 구현해야 한다.
