# Flow 벌크 복구본 v5.6.3

Google Flow에서 긴 프롬프트를 보존한 채 8초·16:9·1개 영상을 순서대로 생성하는 크롬 확장 프로그램입니다.

## 새판 원칙

- 복잡한 API 캡처, 하드코딩 배치, 자동 다운로드 기능은 제거했습니다.
- 안정 우선: `인그리디언트 업로드 -> 입력 -> 생성 버튼 1회 클릭 -> 대기 -> 다음 컷`만 수행합니다.
- 패널에 인그리디언트 이미지가 있으면 시작 시 Flow에 자동 업로드합니다.
- 패널 이미지가 없으면 Flow 작업창에 이미 세팅된 인그리디언트를 그대로 유지합니다.
- 인그리디언트는 최대 3개까지만 사용합니다. 4개 이상 넣으면 앞의 3개만 적용합니다.
- 이미지를 하나씩 추가해도 기존 인그리디언트가 유지됩니다. 새 이미지는 빈 자리만큼 뒤에 추가됩니다.
- 선택된 인그리디언트는 파일명뿐 아니라 썸네일 이미지로 확인할 수 있습니다.
- 패널에 인그리디언트가 들어간 상태에서는 `컷마다 인그리디언트를 바꿀 때만 멈춤` 옵션이 자동으로 꺼집니다.
- 이미지를 선택하지 않으면 Flow 화면에 이미 세팅된 인그리디언트를 그대로 유지합니다.
- 새 프롬프트는 `[S1-01]` 같은 컷번호로 구분합니다. 프롬프트 내부 줄바꿈은 유지됩니다.
- 출력은 기본적으로 8초·16:9·1개로 맞춥니다.
- 중간에 정지한 뒤 `이어서`를 누르면 완료 다음 컷부터 재개합니다.
- 컷마다 인그리디언트를 바꿔야 하면 `컷마다 인그리디언트 직접 확인 후 계속`을 켭니다.

## 설치

1. 크롬에서 `chrome://extensions`를 엽니다.
2. 개발자 모드를 켭니다.
3. `압축해제된 확장 프로그램 로드`를 누릅니다.
4. 이 폴더를 선택합니다.
5. 이미 설치되어 있으면 새로고침 버튼을 누릅니다.

## 사용

1. Google Flow 탭을 활성화합니다.
2. 확장 아이콘을 눌러 사이드패널을 엽니다.
3. 새 인그리디언트를 올릴 때는 패널의 인그리디언트 박스에 이미지를 붙여넣거나 드래그해서 놓습니다.
4. 이미 Flow 작업창에 인그리디언트가 세팅되어 있으면 패널 이미지를 비워두고 프롬프트만 넣습니다.
5. 각 새 프롬프트 첫 줄에 컷번호를 붙입니다. 컷번호가 하나도 없으면 붙여넣은 전체를 영상 한 개로 취급합니다.

```text
[S1-01] USE INGREDIENT 1 as exact Cheolmani...
Opening (0-3s): ...
Mid (3-6s): ...
Late (6-8s): ...

[S1-02] wide shot of a 1970s rural Korean yard...
```

6. 대기 시간을 설정합니다.
7. `시작`을 누릅니다.

## 인그리디언트 업로드 주의

- Flow UI가 바뀌면 업로드 버튼 감지가 실패할 수 있습니다. 이때는 `진단`을 눌러 파일/버튼 후보 로그를 확인합니다.
- 같은 인그리디언트를 이미 Flow 작업창에 올려둔 상태라면 패널 이미지를 비우고 실행하세요. 패널 이미지가 있으면 자동 업로드됩니다.
- 이미지가 너무 크면 Chrome 저장소와 Flow 업로드가 느려집니다. 인그리디언트는 최대 3개까지만 넣으세요.
- 테스트는 1~2장, 2~3프롬프트로 먼저 확인하세요.
- 비용 절감을 위해 전체 12화를 바로 돌리지 말고 같은 인그리디언트 묶음 중 2~3컷만 먼저 테스트합니다.

## 비용/차단 줄이는 설정

- 컷 사이 대기: 35~55초 이상 권장
- 생성 후 대기: 90초 이상 권장
- 계정이 느려지거나 실패가 나오면 컷 사이 대기를 60~90초로 올립니다.
- 먼저 `드라이런`으로 입력창/버튼 감지가 되는지 확인합니다.

## 문제가 생기면

- Flow 탭을 새로고침합니다.
- `chrome://extensions`에서 확장 프로그램 새로고침을 누릅니다.
- 사이드패널 `진단` 버튼을 눌러 입력창/버튼 후보 로그를 확인합니다.
- 자동 감지가 안 되면 고급 설정에 CSS selector를 넣습니다.

## 버전 기록

- `5.6.3` (2026-08-20): 제출된 프롬프트가 입력창에 남아 다음 프롬프트를 밀어내지 못하던 문제 수정. 실제 Backspace로 비우고 편집창과 DOM 캐시를 초기화.
- `5.6.2` (2026-08-20): 생성 후 입력창이 유지되는 Flow 동작을 실패로 오판해 첫 영상 뒤 큐가 멈추던 문제 수정.
- `5.6.1` (2026-08-20): 터치+마우스+폴백으로 동일 요청이 최대 3회 제출되던 문제 수정. 마우스 단일 클릭과 30초 중복 잠금 적용.
- `5.6.0` (2026-08-20): Flow 최신 편집창 대응. 긴 프롬프트 블록 보존, CDP 실제 입력, 8초·16:9·1개 고정, 중단 후 재개, 구버전 동시 실행 차단.

- `5.3.3` (2026-06-18): 프롬프트 입력 후 `more_vert/더 생성하기` 카드 메뉴 버튼을 생성 버튼으로 오인하는 문제 수정. 하단 composer 박스 안의 작은 화살표 버튼만 우선 감지.
- `5.3.2` (2026-06-18): 패널에 이미지가 있으면 시작 시 자동으로 Flow에 업로드하도록 정리.
- `5.3.1` (2026-06-18): 컷당 2장씩 생성되는 Enter 폴백 문제 수정.
- `5.3.0` (2026-06-18): 프롬프트 예시 suggestion 칩을 생성 버튼으로 잘못 누르는 문제 수정.
- `5.2.7` (2026-06-18): 패널 인그리디언트가 있을 때 시작마다 Flow 작업창에 이미지를 다시 주입하던 기본 동작 수정. 이제 기본은 재업로드 생략이며, 별도 체크를 켠 경우에만 Flow 작업창에 이미지 업로드.
- `5.2.6` (2026-06-18): 프롬프트 입력창 자동 감지가 Flow 하단 생성 박스가 아니라 상단 검색창을 잡는 문제 수정. 검색/필터/상단 입력창은 제외하고, `무엇을 만들고 싶으신가요?`가 있는 하단 composer를 우선 감지. 진단 로그에 입력 후보 점수와 차단 여부 표시.
- `5.2.5` (2026-06-18): 생성 버튼 자동 감지가 검색/닫기 버튼을 누르는 문제 수정. 검색/필터/닫기 계열 버튼 제외, 프롬프트 박스 오른쪽 아래 화살표 우선 감지.
- `5.2.4` (2026-06-18): 패널 인그리디언트 사용 시 컷마다 멈춤 옵션 자동 비활성화. 구버전 content script가 남아 있어도 새 명령만 처리하도록 V524 전용 메시지 사용.
- `5.2.3` (2026-06-18): 선택된 인그리디언트를 글자 목록이 아니라 썸네일 카드로 표시해 철만이/마당/소품을 눈으로 확인 가능하게 변경.
- `5.2.2` (2026-06-18): 이미지를 하나씩 붙여넣을 때 기존 인그리디언트가 교체되는 문제 수정. 새 이미지는 기존 목록 뒤에 누적 추가.
- `5.2.1` (2026-06-18): 인그리디언트 최대 3개 제한을 UI에 표시하고, 4개 이상 입력 시 앞의 3개만 사용하도록 안전장치 추가.
- `5.2.0` (2026-06-18): 파일/CSV 중심 흐름을 빼고, 인그리디언트 박스에 붙여넣기/드롭 + 프롬프트 textarea 줄바꿈 방식으로 UI 정리.
- `5.1.0` (2026-06-18): 패널에서 인그리디언트 이미지 업로드 후 줄바꿈 프롬프트를 연속 생성하는 고급 모드 추가.
- `5.0.3` (2026-06-18): 크롬 폴더 선택 혼동 방지를 위해 별도 선택용 폴더 `cheolmani-flow-bulk-v503` 생성.
- `5.0.2` (2026-06-18): 크롬이 구버전 백업 폴더를 계속 읽는 문제를 구분하기 위해 새 작업 폴더 버전을 한 번 더 올림.
- `5.0.1` (2026-06-18): 같은 인그리디언트 벌크 목적을 UI/README에 명확히 표시. 수정 후 버전 숫자 기록 원칙 반영.
- `5.0.0` (2026-06-18): API 캡처/자동 다운로드/하드코딩 배치를 제거하고 프롬프트 연속 입력 중심으로 새판 구성.
