|:---:|---|---|:---:|
| **EP 01** | **금지구역 탈출 (The Escape)**<br>규칙을 어기면 처벌받는 감옥에서 환풍구 하나를 제외하고 모두 잠긴 문을 뚫고 탈출 | `rule`, `unless`, `except`, `despite`, `punish`, `innocent`, `guilt`, `escape` | **8개** |
| **EP 02** | **선택과 대안 런 (The Choice)**<br>둘 다 절망적인 갈림길에서 악마의 유혹을 거부하고 벽을 차고 올라가는 대안 선택 | `neither`, `nor`, `either`, `instead`, `rather`, `otherwise`, `refuse`, `which` | **8개** |
| **EP 03** | **도미노 함정과 인과율 (The Domino)**<br>빨간 버튼을 누른 원인으로 인해 거대한 연쇄 반응이 일어나 벽이 무너지는 결과 | `cause`, `effect`, `influence`, `affect`, `factor`, `therefore`, `thus`, `result` | **8개** |
| **EP 04** | **진실 공방과 팩트 체크 (The Investigation)**<br>범행을 부인하고 우기던 용의자가 탐정의 돋보기 분석과 증거에 굴복해 자백함 | `deny`, `insist`, `argue`, `debate`, `claim`, `convince`, `admit`, `confuse` | **8개** |
| **EP 05** | **연구와 증명 (The Science & Proof)**<br>가설을 세우고 개념을 뼈대 삼아 이론을 수립한 뒤 정밀 분석으로 증명해 냄 | `concept`, `theory`, `analysis`, `assume`, `suppose`, `define`, `method`, `investigate`, `evidence`, `prove` | **10개** |
| **EP 06** | **신뢰와 저항 (Trust & Resistance)**<br>동료를 믿고 서로 의지하며, 거대한 압박과 위협에 맞서 도덕적 용기로 저항함 | `trust`, `belief`, `confirm`, `rely`, `moral`, `protest`, `resist` | **7개** |
| **EP 07** | **사회와 정의 (Justice & Society)**<br>공공의 법과 질서를 지키고, 투표를 통해 대표를 선출하며 공평한 정의를 실현 | `justice`, `law`, `legal`, `civil`, `public`, `private`, `policy`, `politics`, `vote`, `elect`, `govern` | **11개** |
| **EP 08** | **전략과 미션 (Strategy & Success)**<br>명확한 목표와 전략을 세우고, 잠재력을 끌어올려 고난 끝에 마침내 성공을 달성 | `strategy`, `purpose`, `mission`, `target`, `potential`, `achieve`, `succeed`, `success`, `determine` | **9개** |
| **EP 09** | **맥락과 현실 (Context & Reality)**<br>배경과 처한 상황(맥락)에 따라 다르게 대응하며 새로운 환경에 적응해 나감 | `context`, `circumstance`, `instance`, `background`, `version` | **5개** |
| **EP 10** | **접속과 완결 (Logic & Conclusion)**<br>더욱이, 비록 힘들었지만 마침내 진정한 결론에 도달하는 완결의 순간 | `moreover`, `altogether`, `though`, `indeed` | **4개** |

## 🛠️ 4. 후속 AI가 따라야 할 작업 순서 및 명령어

### Step 1. 잔여 단어 풀 확인
```bash
python3 _작업/scene_tool.py remain <챕터번호>
```

### Step 2. 포스터 이미지 실물 확인 후 매칭
- `public/learning/ch{N}/ch{N}_{MM}-poster.jpg` 이미지를 직접 열어 사물을 먼저 확인.
- 억지 추상어 금지. 사물 + 쉬운 풀이로 매칭.

### Step 3. JSON 규격 작성 및 주입
```bash
python3 _작업/scene_tool.py check <편파일.json>
python3 _작업/scene_tool.py add   <편파일.json>
```

### Step 4. 무결성 및 좌표 검증 (필수)
```bash
python3 _작업/scene_tool.py verify
python3 _작업/verify_spots.py public/learning/index.html
```
