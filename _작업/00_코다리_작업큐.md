# 작업 2 — 1200 마스터리스트 뜻 채우기 ⏰ 8/9 크레딧 만료 전

## 대상
`data/1200_마스터리스트_v1.csv` (1,200행)

## 규격서
**No 1~100이 완성본이다. 그 형식을 그대로 따른다.** 예:

```
No,단어,뜻,출처태그,NGSL순위,레벨,장면화등급,...
1,adventure,모험,[NGSL:2667] [1200원본] [초등800제외],2667,★★,[반추상],...
2,bay,만,[NGSL밖] [1200원본] [초등800제외],,★★★,[구체],...
```

## 할 일

**No 101부터 200까지 100개만** `뜻`과 `장면화등급` 두 칸을 채운다.
**101~200을 끝내고 멈춘다. 201번 이후로 넘어가지 않는다.**

### 뜻 작성 규칙
- **한국어로만.** 영어 단어를 그대로 쓰면 실패
- 중학생이 이해할 수 있는 말로. 사전 정의를 옮기지 말 것
- 뜻이 여러 개면 `·`로 구분, **최대 2개** (예: `sail` → `돛·항해하다`)
- 모르는 단어는 비워두고 **「미상」 목록으로 보고.** 지어내지 않는다

### 장면화등급 규칙
| 등급 | 뜻 |
|---|---|
| `[구체]` | 그림에 그대로 보이는 것 (사물·생물·장소) |
| `[반추상]` | 장면 속 행위나 상태 (동사·형용사 대부분) |
| `[추상]` | 그림에 안 보이는 것 (개념·관계·수량) |

## 금지
- 🚫 **생성 스크립트로 일괄 처리 금지.** 한 줄씩 판단한다
- 🚫 「뜻 검수 중」 같은 자리표시자 금지
- 🚫 파일 전체를 다시 쓰지 말고 **해당 100행만** 수정

## 보고
```bash
node -e "
const fs=require('fs');
const rows=fs.readFileSync('data/1200_마스터리스트_v1.csv','utf8').split('\n');
console.log(rows.slice(101,201).join('\n'));
"
```
이 출력 원문 전체를 붙여넣는다. 그리고 아래를 함께 보고한다.
- 뜻을 못 채운 단어 목록 (미상)
- 등급별 개수 (구체/반추상/추상)
